# はじめに

Frost は、自分のサーバーやドライブからクラウドプロバイダーまで、選んだストレージにフォルダをバックアップするツールです。保存の前に、すべてをお使いのコンピュータ上で暗号化します。このページでは、Frost のインストールから最初のバックアップまでを説明します。

## 必要なもの

- 64 ビットの Intel、AMD、ARM プロセッサを搭載した Mac、Linux、Windows のコンピュータ。
- バックアップの保存先。SSH で接続できるサーバー、ドライブ、[Permafrost](#permafrost) のアクセスキー、S3 互換のバケットのいずれかを用意します。比較は[ストレージの選び方](#choosing-storage)にあります。
- 全画面のセットアップ用に、幅 56 列、高さ 18 行以上のターミナルウィンドウ。

Node.js などを事前にインストールする必要はありません。Frost には専用のランタイムが付属しています。

## 1. Frost をインストールする

macOS や Linux では、ターミナルで次のコマンドを実行します。

```sh
curl -fsSL https://getfro.st/install.sh | sh
```

Windows では、PowerShell で次のコマンドを実行します。

```powershell
irm https://getfro.st/install.ps1 | iex
```

インストーラは、何かをインストールする前にリリースの署名を確認します。npm や pnpm でのインストール、手動でのインストール、インストーラのオプションについては、[Frost のインストール](#installing)を参照してください。

## 2. 設定する

```sh
frost init
```

セットアップでは、1 つの画面で 1 つのことだけを尋ねます。

1. **ストレージ。** バックアップの保存先です。Permafrost、S3 互換サービス、自分のサーバー、ドライブのいずれかを選び、質問に答えます。
2. **フォルダ。** バックアップするフォルダです。たとえば `~/Documents` などです。
3. **除外。** バックアップしないファイルやフォルダです。`node_modules` など、よくあるものはあらかじめ入っています。
4. **スケジュール。** Frost が自動でバックアップする頻度です。オフにもできます。
5. **リカバリーフレーズ。** バックアップの鍵を開ける 24 個の単語です。必ず書き留めてください。
6. **確認。** すべてを見直してから `[s]` を押して保存します。

> このコンピュータをなくした場合、バックアップを読む方法はリカバリーフレーズしかありません。バックアップを保管している人も Frost の作者も、代わりに復旧することはできません。

各画面の詳細は[Frost の設定](#setting-up)で説明しています。

## 3. バックアップする

まず、最初のバックアップで何がアップロードされるかを確認します。

```sh
frost backup --dry-run
```

続いて実行します。

```sh
frost backup
```

最初のバックアップではすべてをアップロードします。2 回目以降は変更された部分だけをアップロードします。スケジュールをオンにした場合は、これ以降 Frost が自動でバックアップするので、何も実行する必要はありません。

## 4. 状態を確認する

```sh
frost status
```

`status` には、前回のバックアップ、次回のバックアップの予定、最新のチェック結果、最近のスナップショットが表示されます。

## ファイルを取り戻す

スナップショットブラウザを開き、必要なものを探して `[space]` で選択し、`[r]` を押します。

```sh
frost browse
```

コマンドラインから復元することもできます。次のコマンドは、元のファイルの隣に作る新しいフォルダにファイルのコピーを置きます。

```sh
frost restore latest ~/Documents/report.pdf --beside
```

どちらの方法も[ファイルの復元](#restoring)で説明しています。
