# frost のアップデート

frost は自分自身をアップデートします。既定では、スケジュールされたバックアップのあとに新しいリリースをインストールします。

## 今すぐアップデートする

```sh
frost update
```

frost は最新のリリースを探し、署名とチェックサムを確認し、新しいバージョンが起動することを確かめてから切り替えます。設定、キー、バックアップには手を加えません。

新しいリリースがあるかどうかだけを確認するには、次を実行します。

```sh
frost update --check
```

`frost update` がプレリリースや、今より古いバージョンをインストールすることはありません。

## 自動アップデート

スケジュールされたバックアップのあと、frost は 20 時間に 1 回まで新しいリリースを確認し、`frost update` と同じ方法でインストールします。確認やインストールに失敗しても、バックアップが失敗することはありません。

アップデートの設定と、前回のアップデートが成功したかどうかは `frost status` で確認できます。スナップショットブラウザの設定画面にも表示されます。

新しいリリースの通知だけを受け取り、自動ではインストールしないようにするには、次を実行します。

```sh
frost config set update.auto false
```

これ以降は、新しいリリースが出ると `frost status` で知らせ、`frost update` を実行するまで何もインストールしません。

> 自動アップデートは、スケジュールされたバックアップのあとにだけ実行されます。自動バックアップをオフにしている場合、frost がバックグラウンドでアップデートを確認することはありません。

## frost が自分でアップデートできない場合

| 状況 | 代わりの方法 |
| --- | --- |
| パッケージマネージャ (Homebrew、Nix、Snap、Scoop、システムのパッケージ) で frost をインストールした | そのパッケージマネージャでアップデートします |
| frost のアプリケーションフォルダに書き込めない | 自分のユーザーで、インストーラを使って再インストールします |
| frost をソースからビルドした | ビルドし直すか、インストーラでリリースをインストールします |

アップデートが途中で止まった場合は、インストーラをもう一度実行してください。インストールが修復されます。
