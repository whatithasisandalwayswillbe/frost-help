# リカバリーフレーズ

リカバリーフレーズは、暗号化キーを 24 個の単語で書き表したものです。バックアップを読むための唯一の手段です。

> リカバリーフレーズとコンピュータの両方を失うと、バックアップも失われます。ストレージのプロバイダーも、Permafrost も、frost の作者も、誰も復旧できません。

## 安全に保管する

セットアップは、キーを作るときにリカバリーフレーズを表示します。紙に書き留めるか、信頼できるパスワードマネージャーに保存し、バックアップするコンピュータとは別の場所に保管してください。

スケジュールされたバックアップをあなたがいなくても実行できるように、コンピュータにもコピーが 1 つあります。frost の設定フォルダにある `key` ファイルです。このファイルを読めるのはあなたのユーザーだけです。このファイルを読める人や、あなたとしてプログラムを実行できる人は、バックアップを読むことができます。ディスク全体の暗号化と画面ロックを使ってください。

バックアップを読むには、フレーズとストレージへのアクセス権の両方が必要です。ストレージのキーも人に知られないようにしてください。

## 表示する

```sh
frost key show
```

frost はまず注意を表示し、`show` と入力したあとでだけフレーズを表示します。画面を誰にも見られていないこと、画面共有をしていないことを確認してください。

## 書き写したものを確認する

```sh
frost key verify
```

書き留めたフレーズを入力します。frost は、有効なフレーズかどうか、このコンピュータのキーと一致するかどうか、バックアップを開けるかどうかを教えてくれます。フレーズそのものを表示することはありません。ときどき確認しておきましょう。

## 別のコンピュータで使う

`frost init` は、すでにバックアップがあるストレージに接続するとフレーズを尋ねます。フレーズを直接コンピュータに取り込むには、次を実行します。

```sh
frost key import
```

ストレージが設定済みであれば、frost はまず、そのフレーズでストレージを開けるかを確認します。コンピュータにすでに別のキーがある場合は、置き換える前に確認します。古いキーで作ったバックアップを復元するには、古いフレーズが必要です。

手順の全体は[新しいコンピュータでの復元](#new-computer)を参照してください。

## フレーズの入力

24 個の単語を順番どおりに、スペースで区切って入力します。大文字と小文字は区別しません。単語は 2,048 語からなる標準の BIP39 英単語リストから選ばれているので、つづりが間違っていれば frost が指摘できます。

| frost の表示 | 意味 |
| --- | --- |
| that's 23 words, a recovery phrase has 24 | 単語が 1 つ足りないか、多すぎます |
| word 5, "hapy", isn't a recovery phrase word | その単語のつづりが間違っています |
| all the words are real, but they don't make a valid phrase | 2 つの単語が入れ替わっているか、1 つが別の実在する単語になっています |
| that's a valid phrase, but not the one for these backups | 別のバックアップのフレーズです |

## キーのフィンガープリント

フィンガープリントは、`6f154dc10058` のような短い ID で、キーそのものを明かさずにキーを識別します。`frost status` に表示され、スナップショットブラウザでも `[v]` を押すと表示されます。フィンガープリントが同じ 2 台のコンピュータは、同じキーを持っています。

## キーを変える

frost では、既存のバックアップのキーを変えることはできません。誰かにフレーズを見られたかもしれない場合、その人はストレージにアクセスできる限り、それらのバックアップを読めます。ストレージのキーを変更し、人に知られないようにしてください。
