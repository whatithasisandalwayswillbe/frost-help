# ヘルプ

このドキュメントに載っていない問題については、次の方法で詳しく調べたり、助けを求めたりできます。

## まず確認すること

- `frost status` には、前回のバックアップの結果、バックアップの健全性、ストレージへの接続の問題が表示されます。
- `frost -h` で、すべてのコマンドとオプションを一覧できます。
- スケジュールされたバックアップのログには、自動バックアップ中に起きたことが記録されています。詳しくは[自動バックアップ](#scheduling)を参照してください。
- [よくある問題](#common-problems)に、よく見かけるメッセージをまとめています。

## GitHub で質問する

[github.com/whatithasisandalwayswillbe/frost/issues](https://github.com/whatithasisandalwayswillbe/frost/issues) で issue を作り、次の情報を書いてください。

- frost のバージョン (`frost --version` で確認できます) と OS。
- 何を実行し、どうなると思っていたか。
- 実際に何が起きたか。メッセージはそのまま書いてください。
- `frost status` やログの関係する行。

> リカバリーフレーズ、キーファイル、アクセスキー、認証情報を含む `config.toml` は決して投稿しないでください。`frost config` は、`--show-secrets` を付けない限り認証情報を伏せて表示します。貼り付ける内容は、投稿する前に必ず見直してください。

## セキュリティ上の問題

セキュリティ上の問題は、公開の issue で報告しないでください。非公開で報告する方法は[セキュリティとプライバシー](#security)を参照してください。
