# 新しいコンピュータでの復元

コンピュータをなくした、壊れた、買い替えた、といった場合も、別のコンピュータでファイルを取り戻せます。

## 必要なもの

- 24 単語のリカバリーフレーズ。
- ストレージの情報。Permafrost のアクセスキー、または S3 プロバイダーのバケット名とアクセスキーです。

古いコンピュータがまだ手元にあれば、`frost key show` でフレーズを表示できます。

## 手順

1. 新しいコンピュータに [frost をインストール](#installing)します。
2. `frost init` を実行し、以前と同じ情報で同じストレージを選びます。
3. セットアップがバックアップを見つけ、そのリカバリーフレーズを尋ねます。24 単語をすべて入力します。
4. このコンピュータでバックアップするフォルダ、除外リスト、スケジュールを選び、確認して保存します。
5. このコンピュータが最初のバックアップを行う前に、ファイルを復元します。

```sh
frost restore latest --to ~
```

これで、最新のスナップショットがホームフォルダ内の新しい `frost-restore-<id>` フォルダに、元のフォルダと同じ構成で復元されます。2 台が同じ種類のコンピュータなら、`/Users/you/Documents` のように古いコンピュータでのパスを付けて、一部だけを復元することもできます。

Mac のスナップショットを Windows で復元する場合など、種類の違うコンピュータから復元するものを選ぶときは、スナップショットブラウザを使います。`frost browse` を実行し、必要なものを選んで `[r]` を押し、"New folder elsewhere" を選びます。

`--beside` や `--overwrite` ではなく `--to` を使ってください。`--beside` は元のフォルダがこのコンピュータにあることが前提で、`--overwrite` は同じ種類のコンピュータ (macOS と Linux、または Windows) のスナップショットでなければ使えません。

> このコンピュータが最初のバックアップを行う前に復元してください。バックアップしたあとは、`latest` はこのコンピュータ自身の最新スナップショットを指すようになります。すでにバックアップしてしまった場合は、`frost status` で古いスナップショットの ID を調べ、そちらを復元してください。

## 2 台のコンピュータで 1 つのストレージを使う

同じリカバリーフレーズを使えば、2 台のコンピュータから同じストレージにバックアップできます。スナップショットは 1 つの一覧にまとまり、両方にあるデータは 1 回しか保存されません。

この場合、`latest` はどちらかのコンピュータの最新のスナップショットを指します。スナップショットブラウザの詳細パネルで、各スナップショットをどのコンピュータが作ったかを確認できます。特定のコンピュータのファイルを復元するときは、そのスナップショットを ID で指定してください。

## フレーズをなくした場合

古いコンピュータがまだ動くなら、そこで `frost key show` を実行してください。フレーズもコンピュータも失った場合、バックアップは誰にも復号できません。詳しくは[リカバリーフレーズ](#recovery-phrase)を参照してください。
