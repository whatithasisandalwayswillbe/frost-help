# スナップショットブラウザ

`frost browse` は、全画面のスナップショットブラウザを開きます。当時のままのファイルを見て回ったり、スナップショットを比較したり、選んだものを復元したりできます。

```sh
frost browse
```

`frost restore` を引数なしで実行しても、ブラウザが開きます。ブラウザを開いている間も、スケジュールされたバックアップは実行できます。

## 移動

| キー | 動作 |
| --- | --- |
| `[↑]` `[↓]` または `[k]` `[j]` | 移動 |
| `[pgup]` `[pgdn]` | 1 ページずつ移動 |
| `[g]` `[G]` | 先頭または末尾に移動 |
| `[enter]` | 開く |
| `[esc]` | 戻る、またはエラーを閉じる |
| `[h]` | すべてのキーを表示 |
| `[s]` | 設定を表示 |
| `[v]` | キーのフィンガープリントの表示を切り替える |
| `[q]` | 終了 |

設定画面は表示専用です。設定の変更には `frost config set` か `frost config edit` を使います。

## ホーム

ホーム画面には、前回のバックアップと最新のチェック結果が表示されます。`[enter]` でスナップショットの一覧へ進み、`[r]` で表示を更新します。

## スナップショット

スナップショットは新しい順に、日付ごとにまとめて表示されます。ウィンドウの幅が広いと、一覧の横のパネルに、ハイライトしたスナップショットの詳細が表示されます。作成日時、どのコンピュータで作られたか、ファイル数、サイズ、追加された新しいデータの量がわかります。

| キー | 動作 |
| --- | --- |
| `[enter]` | スナップショットのファイルを開く |
| `[d]` | 1 つ前のスナップショットと比較する |
| `[m]` | マークする。続けて別のスナップショットで `[d]` を押すと、2 つを比較します |

比較すると、2 つのスナップショットの間で追加、削除、変更されたものが一覧表示されます。

## ファイル

そのスナップショットの時点のフォルダとファイルが、そのままの形で表示されます。

| キー | 動作 |
| --- | --- |
| `[enter]` | フォルダを開く |
| `[←]` | 親フォルダに戻る |
| `[space]` | 選択または選択解除 |
| `[a]` | このフォルダ内のすべてを選択または選択解除 |
| `[c]` | 選択をすべて解除 |
| `[r]` | 選択したものを復元する。何も選択していなければ、ハイライトしている項目を復元します |

## 復元

`[r]` を押したら、ファイルの復元先を選びます。

| キー | 選択肢 | 動作 |
| --- | --- | --- |
| `[1]` | New folder beside originals | 元のファイルの隣の新しいフォルダに復元します。`frost restore --beside` と同じです |
| `[2]` | New folder elsewhere | フォルダを選び、その中の新しいフォルダに復元します |
| `[3]` | Overwrite original files | 元のファイルを置き換えます。`frost restore --overwrite` と同じです。`[y]` で確定します |

何かを書き込む前に、frost はそれぞれがどこに置かれるかを表示します。`[enter]` で復元し、`[c]` でフォルダを変え、`[esc]` でキャンセルします。長い確認画面や結果は `[pgup]` と `[pgdn]` でスクロールできます。

"New folder elsewhere" を選ぶと、システムのフォルダ選択画面が開きます。macOS では Finder、Windows ではエクスプローラー、Linux では zenity、qarma、matedialog のいずれかです。SSH 経由の場合や、フォルダ選択画面がない Linux では、フォルダを入力します。選択画面が開いている間に `[t]` を押すと、入力に切り替えられます。

復元が終わると、frost は復元したものを Finder、エクスプローラー、または Linux のファイルマネージャで表示します。ファイル 1 つだけなら選択された状態で表示し、それ以外はすべてを含むフォルダを開きます。SSH 経由の場合、画面がない場合、復元に失敗した場合は、何も開きません。

各選択肢の詳細と、復元が中断した場合の動作は、[ファイルの復元](#restoring)で説明しています。
