# ファイルの除外

除外リストに入れたファイルやフォルダは、どのバックアップにも含まれません。設定ファイルでは `exclude` という名前です。

## 既定値

新しい除外リストには `.DS_Store`、`Thumbs.db`、`*.tmp`、`*.swp`、`node_modules`、`.cache` が入っています。バックアップしたいものがあれば削除してください。

## パターンの書き方

- **スラッシュを含まない名前やパターン**は、どこにあっても、その名前のファイルやフォルダに一致します。`node_modules` と書けば、すべての `node_modules` フォルダとその中身が除外されます。
- **スラッシュを含むパターン**はフルパスです。そのパスと、その下にあるものすべてを除外します。`~` はホームフォルダを表し、`~/Downloads/Movies` のように書けます。

パターンでは次のワイルドカードが使えます。

| ワイルドカード | 一致するもの |
| --- | --- |
| `*` | `/` 以外の任意の数の文字 |
| `?` | `/` 以外の任意の 1 文字 |
| `[abc]` | 並べた文字のどれか 1 つ。`[a-z]` は範囲指定、`[^abc]` は並べた文字以外の 1 文字です |
| `\` | 次の文字をそのまま扱います。`\*` は文字どおりの `*` に一致します |

パターンは大文字と小文字を区別します。そのため、`*.MOV` では `clip.mov` は除外されません。

リストにあるフォルダそのものが除外されることはなく、除外されるのはその中にあるものだけです。

## 例

| パターン | 除外されるもの |
| --- | --- |
| `*.iso` | すべてのディスクイメージ |
| `.git` | すべての Git フォルダ |
| `Cache*` | 名前が `Cache` で始まるものすべて |
| `~/Library/Caches` | macOS のホームフォルダにあるキャッシュフォルダ |
| `~/Videos/*.mov` | `~/Videos` の直下にある `.mov` ファイル。サブフォルダ内のものは含みません |

## リストを変更する

`frost init` を実行して除外の画面で変更するか、`frost config edit` を使います。次のように 1 つのコマンドでリスト全体を設定することもできます。この場合、既存のリストは置き換えられます。

```sh
frost config set exclude .DS_Store node_modules '*.tmp' '~/Downloads'
```

`*` や `~` を含むパターンは、シェルに先に展開されないよう引用符で囲んでください。

1 回のバックアップだけで何かを除外するには、次を実行します。

```sh
frost backup --exclude '*.iso'
```

除外しても、すでにあるスナップショットからそのファイルが消えるわけではありません。
