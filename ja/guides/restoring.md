# ファイルの復元

どのスナップショットからでも、新しいフォルダに、または元のファイルに上書きして、ファイルを取り戻せます。

いちばん簡単なのはスナップショットブラウザを使う方法です。`frost browse` を実行し、必要なものを探して `[space]` で選択し、`[r]` を押します。詳しくは[スナップショットブラウザ](#snapshot-browser)を参照してください。このページでは、コマンドラインから復元する方法を説明します。

## restore コマンド

```sh
frost restore <snapshot> [paths...] --beside | --to <dir> | --overwrite
```

- **スナップショット**: どのスナップショットから復元するかです。下の「スナップショットの指定」を参照してください。
- **パス**: 復元するファイルやフォルダです。それぞれ中身もすべて含みます。省略するとスナップショット全体を復元します。
- **復元先**: `--beside`、`--to`、`--overwrite` のどれか 1 つを必ず指定します。

例:

```sh
frost restore latest ~/Documents/taxes --beside
frost restore yesterday ~/notes.txt --to ~/Desktop
frost restore maple-absurd-3f1c --overwrite
```

`frost restore` を引数なしで実行すると、スナップショットブラウザが開きます。

## スナップショットの指定

| 入力 | 選ばれるもの |
| --- | --- |
| `latest` | 最新のスナップショット |
| `maple-absurd-3f1c`、または `maple` だけ | その ID のスナップショット、または ID が入力した文字列で始まる唯一のスナップショット |
| `3 days ago`、`12h`、`2w`、`1 month ago` | その時点か、それより前で最新のスナップショット |
| `yesterday`、`today` | その日の終わりまでで最新のスナップショット |
| `2026-09-20`、`2026-09-20 14:30` | その日またはその分か、それより前で最新のスナップショット (ローカル時刻) |

相対的な時間は英語で書きます。分 (`m`)、時間 (`h`)、日 (`d`)、週 (`w`)、月 (`mo`)、年 (`y`) が使え、単語をそのまま書くこともできます。`"3 days ago"` のように、スペースを含むものは引用符で囲んでください。

スナップショットとその ID は `frost status` で一覧できます。入力が複数の ID に当てはまる場合は、もっと長く入力するよう frost が求めます。

## 復元先

| オプション | 復元先 |
| --- | --- |
| `--beside` | 元のファイルの隣に作る新しい `frost-restore-<id>` フォルダ |
| `--to <dir>` | `<dir>` の中に作る新しい `frost-restore-<id>` フォルダ。`<dir>` はあらかじめ存在している必要があります |
| `--overwrite` | 元の場所。そこにあるものを置き換えます。frost は事前に確認し、`-y` でその確認を省略できます |

新しいフォルダに復元する場合、何かが上書きされることはありません。新しいフォルダの中では、復元したものは元の名前のまま、選んだものに共通するフォルダを基準に並びます。

| 復元するもの | `--beside` の結果 |
| --- | --- |
| `~/Documents/taxes` | `~/Documents/frost-restore-<id>/taxes/...` |
| `~/notes.txt` | `~/frost-restore-<id>/notes.txt` |
| `~/Documents/a` と `~/Pictures/b` | `~/frost-restore-<id>/Documents/a` と `~/frost-restore-<id>/Pictures/b` |

新しいフォルダの名前には、スナップショットの短い ID が使われます。その名前がすでにある場合は、frost が `-1`、`-2` のように番号を付けます。

選んだものに共通するのがドライブの最上位だけの場合、そのフォルダがこのコンピュータにない場合 (別のコンピュータのスナップショットなど)、そこに書き込めない場合は、`--beside` を使えません。たとえば、ホームフォルダ全体のスナップショットを元の場所の隣に復元すると、`/Users` や `/home` に新しいフォルダを作ることになります。このような場合は `--to` を使ってください。

## 元のファイルに上書きして復元する

`--overwrite` は、ファイルを元の場所に戻し、そこにあるものを置き換えます。frost はこれから行うことを表示し、事前に確認します。

```text
┌  restore maple-absurd-3f1c  2026-10-07 03:17 (1d ago)
│
│  paths        /home/you/Documents/taxes
▲  into         original locations (existing files will be replaced)
│
│  Go ahead? [y/N]
```

- スナップショットとすでに一致しているファイルは、確認したうえでスキップするので、もう一度ダウンロードすることはありません。
- スナップショットに含まれていないファイルには手を付けません。
- 各ファイルは、まずその隣の隠し一時ファイルに書き込まれ、そのあとで入れ替えられます。復元中のファイルについて、2 つ分のコピーが入る空き容量が必要です。
- スナップショットは同じ種類のコンピュータのものである必要があります。macOS と Linux のスナップショットは macOS か Linux に、Windows のスナップショットは Windows に上書きできます。
- ほかのユーザーが変更できたフォルダのリンクを経由する場合、frost は復元しません。それが原因のときは確認の前にその旨を伝え、ブラウザでは "Overwrite original files" が灰色表示になります。

## 安全のためのチェック

各チャンクは、書き込む前に復号し、ID と照合します。各ファイルは完成して初めて本来の名前になるので、復元に失敗しても、本物のファイルがあった場所に書きかけのファイルが残ることはありません。

復元したシンボリックリンクは元のリンク先を保ちます。リンク先は復元フォルダの外を指している場合もあります。

## 中断した復元

接続が切れた、`Ctrl+C` を押した、コンピュータがスリープした、などの理由で復元が止まると、frost は続きを実行するコマンドを表示します。

```text
What's restored so far was kept. To carry on from there, run:

  frost restore maple-absurd-3f1c9a0b2e7 /home/you/Documents/taxes --beside
```

これは同じ復元を、`latest` や日時の代わりにスナップショットの完全な ID で指定したものです。そのため、間にバックアップが入っても、対象のスナップショットは変わりません。復元済みのファイルは確認してスキップし、書き込み途中だったファイルは最後の正常なチャンクから続けます。Windows では、パスによって PowerShell のコマンドが必要になります。その場合は、PowerShell で実行するようメッセージに表示されます。

復元が終わるまで、復元先のフォルダには `.frost-restore` マーカーと `.frost-partial-...` ファイルが置かれます。触らずにそのままにしておいてください。完了すると frost が削除します。

コンピュータをなくしたあとに復元する方法は、[新しいコンピュータでの復元](#new-computer)を参照してください。
