# バックアップの確認

frost はバックアップのたびに状態を確認しています。その結果は `frost status` で見られます。

## frost status

```sh
frost status
```

```text
┌  frost  v0.1.0  s3://my-backups/frost/  key 6f154dc10058
│
│  last backup  ok 2h ago  maple-absurd-3f1c
│  next backup  ~in 4h  6h via launchd
│  health       ok 21 objects checked 2h ago
│  updates      automatic
│  protected    1,204 files, 2.1 GB, in 3 snapshots
│
├  snapshots
│
│  snapshot             taken                  files         size          new
│  maple-absurd-3f1c    2026-10-08 09:17       1,204       2.1 GB      14.2 MB
│  orbit-velvet-a02e    2026-10-08 03:17       1,201       2.1 GB       3.6 MB
│  canyon-pilot-77b9    2026-10-07 21:17       1,198       2.1 GB       2.1 GB
└
```

1 行目には、frost のバージョン、ストレージ、キーのフィンガープリントが表示されます。その下の各行の意味は次のとおりです。

| 行 | 表示内容 |
| --- | --- |
| last backup | 前回のバックアップの日時と成否。"ok, but" のあとには、見つからなかったフォルダ、読めなかった項目、以前のコピーを残した使用中のファイルが並びます |
| next backup | 次の自動バックアップの予定。自動バックアップがオフならそのことを表示します |
| health | 最新の抜き取りチェックの結果 |
| updates | アップデートが自動かどうかと、新しいリリースが出ているかどうか |
| protected | 最新スナップショットのファイル数とサイズ、スナップショットの総数 |
| missing | このコンピュータが把握していたのに、ストレージから消えたスナップショット |

一覧には最新の 10 個のスナップショットが表示されます。`new` の列は、それぞれのスナップショットで追加された新しいデータの量です。すべてを表示するには、次を実行します。

```sh
frost status --all
```

## 抜き取りチェック

スナップショットを保存したバックアップのたびに、frost は無作為に選んだチャンクをダウンロードし、1 つずつ復号して ID と一致するかを確認します。さらに、最新スナップショットのファイル一覧を読み込み、必要なチャンクをすべて frost が把握しているかも確認します。新しい内容がないバックアップでは、前回のチェックから 1 日以上経っているか、前回問題が見つかった場合にだけチェックし直します。

既定では 20 個のチャンクを調べます。数を増やすと見つかる問題は増えますが、ダウンロード量も増えます。

```sh
frost config set verify.sample 50
```

`0` にすると、抜き取りチェックはオフになります。

## 今すぐ確認する

```sh
frost status --verify
```

新しく抜き取りチェックを行い、さらに frost が手元で記録しているチャンクの一覧とストレージの中身をすべて照合します。`verify.sample` が `0` でも、このコマンドは 20 個のチャンクを調べます。チェックに失敗すると `1` で終了するので、自分のスケジューラから実行して、バックアップとは別の頻度で確認できます。

## チェックに失敗したとき

health の行に、失敗した内容が表示されます。たいていは、ストレージがいくつかのチャンクを失ったか壊したことを意味します。

1. `frost backup` を実行します。失われたチャンクのうち、データがまだコンピュータにあるものはもう一度アップロードされます。
2. `frost status --verify` を実行して、もう一度確認します。

コンピュータからすでに消えたデータはアップロードし直せません。そのデータが必要な古いスナップショットは、完全には復元できなくなります。ストレージに残っていても壊れているチャンクは、バックアップでは自動的に置き換わりません。プロバイダーや別の独立したバックアップから正常なコピーを取り戻し、もう一度確認してください。

## 消えたスナップショット

このコンピュータが把握していたスナップショットがストレージから消えると、`frost status` が一度だけ知らせます。バックアップを移動した場合は、frost に新しい場所を設定してください。詳しくは[バックアップの移動](#moving-backups)を参照してください。そうでなければ、ストレージから削除されています。

> 抜き取りチェックは、バックアップの一部を調べるものです。問題を早く見つけられますが、すべてのスナップショットが復元できることを保証するものではありません。失っては困るファイルは、別の独立したバックアップも用意してください。
