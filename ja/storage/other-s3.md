# その他の S3 互換ストレージ

MinIO や Ceph、セットアップに専用の項目がないプロバイダーなど、S3 プロトコルを使うほかのサービスも使えます。ただし、条件付き書き込みに対応している必要があります。詳しくは[ストレージの選び方](#choosing-storage)を参照してください。

## セットアップでの入力

`frost init` を実行し、**Other S3-compatible** を選びます。

| セットアップの質問 | 答え |
| --- | --- |
| What's the S3 endpoint? | プロバイダーのドキュメントに書かれたホスト名。`https://` を付けずにホスト名だけを書くと HTTPS で接続します |
| Which region? | プロバイダーに求められた場合だけ入力します。それ以外は空欄のままにします |
| What's the bucket called? | 作成したとおりのバケット名。バケットはあらかじめ作っておく必要があります |
| Paste the access key ID. | プロバイダーのコンソールで確認します |
| Paste the secret access key. | プロバイダーのコンソールで確認します |

frost は、バケット内の `frost` フォルダにバックアップを保存します。

## TLS を使わないサーバー

自分のコンピュータやネットワークで動かすテスト用サーバーには、`http://localhost:9000` のように `http://` を付けたエンドポイントを指定します。この場合、すべての通信で TLS が無効になるので、信頼できるネットワークでだけ使ってください。`storage.s3.insecure` を `true` にすると、スキームのないエンドポイントで HTTP を使います。`https://` や `http://` を明示した場合は、そちらが優先されます。

## バケット内のフォルダ

frost は、バケット内の 1 つのフォルダにすべてを保存します。既定は `frost` です。全画面のセットアップではこのフォルダについて尋ねません。

セットアップが完了したあと、最初のバックアップの前に別のフォルダやバケットの最上位を使いたい場合は、次のようにします。

1. `frost config edit` を実行し、`[storage.s3]` の `prefix` を変更します。バケットの最上位を使うなら空にします。そこにはまだバックアップがないと frost が警告するので、`yes` と入力してそのまま保存します。
2. `frost init` をもう一度実行します。確認画面に、別系統のバックアップを始めることになるという警告が出るので、`[s]` を押して進みます。

すでにバックアップがある場合は、代わりにそれを移動してください。方法は[バックアップの移動](#moving-backups)で説明しています。

## MinIO

MinIO のサーバーは条件付き書き込みに対応していますが、使っているバージョンがセットアップのテストに通る必要があります。MinIO のコンソールでバケットとアクセスキーを作り、`https://<server>:9000` のように、MinIO サーバーのアドレスとポートをセットアップに入力します。
