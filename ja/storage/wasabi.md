# Wasabi

Wasabi のバケットにバックアップします。

> Wasabi のドキュメントからは、frost に必要な条件付き書き込みに対応しているかを確認できません。セットアップは接続時にこれをテストします。テストに通らない場合は、別のプロバイダーを選んでください。詳しくは[ストレージの選び方](#choosing-storage)を参照してください。

## 始める前に

1. Wasabi のコンソールでバケットを作り、`us-east-1` や `eu-central-1` のようなリージョンを控えておきます。
2. アクセスキーを作成します。場所は Access Keys > Create New Access Key です。できれば、このバケットにしかアクセスできないユーザーを使ってください。

## セットアップでの入力

`frost init` を実行し、**Wasabi** を選びます。

| セットアップの質問 | 答え |
| --- | --- |
| Which region is the bucket in? | バケットのリージョン。たとえば `us-east-1` |
| What's the bucket called? | 作成したとおりのバケット名 |
| Paste the access key. | 作成したアクセスキー |
| Paste the secret key. | キーの作成時に一度だけ表示されます |

frost は `s3.<region>.wasabisys.com` に接続し、バケット内の `frost` フォルダにバックアップを保存します。

## 知っておきたいこと

frost のフォルダ内のオブジェクトを削除するライフサイクルルールは追加しないでください。スナップショット同士はチャンクを共有しているので、オブジェクトを 1 つ消すだけで多くのスナップショットが壊れることがあります。
