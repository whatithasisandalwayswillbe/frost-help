# ストレージの選び方

frost は、Permafrost か、条件付き書き込みに対応した S3 互換プロバイダーにバックアップを保存します。どちらの場合も、すべてがコンピュータを出る前に暗号化されるので、プロバイダーが中身を読むことはできません。

## 選択肢

- **[Permafrost](#permafrost)** は、frost のために作られたホスト型ストレージです。必要なのはアクセスキー 1 つだけで、バケット、リージョン、エンドポイントを設定する必要はありません。
- **S3 互換ストレージ**では、[Amazon S3](#amazon-s3)、[Cloudflare R2](#cloudflare-r2)、[Backblaze B2](#backblaze-b2)、[Wasabi](#wasabi) などのプロバイダーで作ったバケットや、[MinIO](#other-s3) のように自分で運用するサーバーを使います。

## 条件付き書き込み

frost には、アトミックな条件付き書き込み (`If-None-Match: *`) に対応したストレージが必要です。これにより、2 台のコンピュータがお互いのバックアップ記録を上書きし合うことを防ぎます。セットアップは接続時にこれをテストし、通らないストレージは使いません。プロバイダー自体が対応していない場合、キーや設定を変えても解決しません。

| プロバイダー | 条件付き書き込み |
| --- | --- |
| Permafrost | 対応 |
| Amazon S3 | [ドキュメントに記載あり](https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-writes.html) |
| Cloudflare R2 | [ドキュメントに記載あり](https://developers.cloudflare.com/r2/api/s3/api/) |
| MinIO | サーバーに実装済み。使っているバージョンがセットアップのテストに通る必要があります |
| Backblaze B2 | 未確認。[アップロードのリファレンス](https://www.backblaze.com/apidocs/s3-put-object)に `If-None-Match` の記載がありません |
| Wasabi | 未確認。[API リファレンス](https://docs.wasabi.com/apidocs/operations-on-objects)からは対応を確認できません |
| Garage | 非対応 (メンテナーによる) |

この表は、2026 年 10 月 2 日に各プロバイダーのドキュメントとソースコードで確認したもので、実際の動作テストは行っていません。最終的にはセットアップ自身のテストで判断します。

## 検討すること

- **復元にかかる費用。** ダウンロードに料金がかかるプロバイダーもあります。全体を復元するとすべてをダウンロードしますし、抜き取りチェックのたびに少量のダウンロードも発生します。
- **アーカイブ用のストレージクラス。** frost はチャンクを直接読み戻すので、読む前に取り出し作業が必要なアーカイブ用クラスに、frost のオブジェクトを移さないでください。
- **削除と有効期限。** frost がバックアップを削除することはありません。スナップショット同士はチャンクを共有しているので、frost のフォルダ内のオブジェクトを削除したり期限切れにしたりするライフサイクルルールは追加しないでください。
- **権限を絞ったキー。** frost には、専用のバケットにしかアクセスできないアクセスキーを渡してください。

## あとからストレージを変える

すべてをアップロードし直すことなく、バックアップを別のプロバイダーに移せます。詳しくは[バックアップの移動](#moving-backups)を参照してください。
