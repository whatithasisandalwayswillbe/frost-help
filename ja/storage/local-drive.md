# ローカルドライブ

外付けの USB ドライブ、2 台目の内蔵ディスク、ドックに挿したドライブなど、ドライブ上のフォルダにバックアップします。ほかのストレージと同じようにすべて暗号化されるので、ドライブをなくしてもファイルの中身が漏れることはありません。

## セットアップでの入力

`frost init` を実行し、**Local drive** を選んで、接続されているドライブ上のフォルダの絶対パスを入力します。

| システム | 例 |
| --- | --- |
| macOS | `/Volumes/Backup/frost` |
| Linux | `/mnt/backup/frost` または `/media/<you>/Backup/frost` |
| Windows | `E:\frost` |

パスの最後のフォルダがなければ、セットアップが作ります。その親フォルダ (通常はドライブそのもの) は存在している必要があります。

## ドライブが接続されていないとき

Frost がフォルダを作るのはセットアップのときだけです。バックアップの実行時にドライブが接続されていなければフォルダが見つからず、ドライブを接続するよう求めるメッセージとともにバックアップは失敗します。そのパスにほかの何かがあっても、そこにバックアップを書き込むことはありません。スケジュールされたバックアップは、ドライブがまだマウント中の場合に備えて、まず約 5 分間ドライブを待ちます。

Windows では、ドライブを接続し直すと別のドライブ文字が割り当てられることがあります。ディスクの管理で元の文字に戻すか、`frost init` を実行して新しいパスを入力してください。

## 別の場所にもコピーを置く

コンピュータのそばにあるドライブは、コンピュータと一緒になくしたり、盗まれたり、壊れたりすることがあります。かけがえのないものは、家の外に保管するドライブや、別の場所にある[セルフホスト](#self-hosted)のサーバーなど、別の場所にももう 1 つコピーを置いてください。リポジトリのコピー方法は[バックアップの移動](#moving-backups)で説明しています。

## ネットワーク共有

NAS には、たいてい[セルフホスト](#self-hosted)のほうが適しています。コンピュータにマウントしたネットワーク共有は、そのファイルシステムが安全にファイルを作れる場合にだけ使えます。セットアップは接続時にこれを確認します。Windows では、割り当てたドライブ文字ではなく、共有の `\\server\share` というパスを使ってください。スケジュールされたバックアップからは、割り当てたドライブ文字が見えない場合があります。

## 知っておきたいこと

- Frost はフォルダ内のリンクやジャンクションをたどりません。Windows では、リンクやジャンクションを経由してたどり着くフォルダも拒否します。フォルダの実際のパスを使ってください。
- macOS では、スケジュールされたバックアップがリムーバブルドライブやネットワークドライブを使うための許可が必要です。詳しくは[macOS の権限](#macos-permissions)を参照してください。
- `frost status` はドライブの使用状況を表示し、`frost backup` はほぼいっぱいになると警告します。
- NTFS、APFS、ext4、Btrfs、XFS でフォーマットされたドライブが使えます。exFAT や FAT のドライブは、セットアップの確認に通れば使えます。
