# Backblaze B2

Резервное копирование в бакет Backblaze B2 через его S3-совместимый API.

> В документации Backblaze не сказано, поддерживает ли B2 условную запись, которая нужна frost. Мастер настройки проверяет это при подключении. Если проверка не пройдена, выберите другого провайдера. Подробнее в разделе [Выбор хранилища](#choosing-storage).

## Перед началом

1. Создайте бакет в своей учётной записи Backblaze.
2. Запишите его эндпоинт: Buckets > your bucket > Endpoint. Он выглядит как `s3.us-west-004.backblazeb2.com`.
3. Создайте ключ приложения: Application Keys > Add a New Application Key. Ограничьте его этим бакетом.

## В мастере настройки

Выполните `frost init` и выберите **Backblaze B2**.

| Вопрос мастера | Ответ |
| --- | --- |
| What's the bucket's endpoint? | Эндпоинт со страницы бакета, например `s3.us-west-004.backblazeb2.com` |
| What's the bucket called? | Имя бакета, точно как при создании |
| Paste the application key's keyID. | keyID нового ключа приложения |
| Paste the applicationKey. | Показывается один раз, сразу после создания ключа |

frost определяет регион по эндпоинту и хранит копии в папке `frost` внутри бакета.

## Полезно знать

Не добавляйте правила жизненного цикла, которые удаляют объекты из папки frost. Снимки используют общие блоки, и удаление одного объекта может испортить сразу многие снимки.
