# Выбор хранилища

frost хранит копии в Permafrost или у любого S3-совместимого провайдера, который поддерживает условную запись. В обоих случаях всё шифруется до того, как покинет ваш компьютер, поэтому провайдер не может ничего прочитать.

## Варианты

- **[Permafrost](#permafrost)** представляет собой хостинговое хранилище, созданное для frost. Ему нужен только ключ доступа, а бакет, регион и эндпоинт настраивать не придётся.
- **S3-совместимое хранилище** использует бакет, который вы создаёте у провайдера, например [Amazon S3](#amazon-s3), [Cloudflare R2](#cloudflare-r2), [Backblaze B2](#backblaze-b2) или [Wasabi](#wasabi), или на собственном сервере, например [MinIO](#other-s3).

## Условная запись

frost нужно хранилище с поддержкой атомарной условной записи (`If-None-Match: *`). Она не даёт двум компьютерам перезаписывать служебные записи копий друг друга. Мастер настройки проверяет это при подключении и не принимает хранилище, которое проверку не проходит. Если провайдер этого не поддерживает, другие ключи или настройки не помогут.

| Провайдер | Условная запись |
| --- | --- |
| Permafrost | Поддерживается |
| Amazon S3 | [Описана в документации](https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-writes.html) |
| Cloudflare R2 | [Описана в документации](https://developers.cloudflare.com/r2/api/s3/api/) |
| MinIO | Реализована в сервере. Ваша версия должна пройти проверку мастера |
| Backblaze B2 | Не подтверждена. В [справке по загрузке](https://www.backblaze.com/apidocs/s3-put-object) нет `If-None-Match` |
| Wasabi | Не подтверждена. [Справка по API](https://docs.wasabi.com/apidocs/operations-on-objects) не подтверждает поддержку |
| Garage | Не поддерживается, по словам сопровождающего |

Эти сведения проверены по документации и исходному коду провайдеров 2 октября 2026 года, без реальных тестов. Решающее слово за проверкой самого мастера.

## Что учесть

- **Стоимость восстановления.** Некоторые провайдеры берут плату за скачивание. Полное восстановление скачивает всё, а каждая выборочная проверка скачивает небольшую выборку.
- **Архивные классы хранения.** frost читает блоки напрямую, поэтому не переносите его объекты в архивный класс, из которого данные нужно сначала извлекать.
- **Удаление и истечение срока.** frost никогда не удаляет ваши копии. Не добавляйте правила жизненного цикла, которые удаляют объекты из его папки или ограничивают срок их хранения: снимки используют общие блоки.
- **Ограниченные ключи.** Дайте frost ключ доступа, который открывает только его собственный бакет.

## Сменить хранилище позже

Копии можно перенести к другому провайдеру, не отправляя всё заново. Подробнее в разделе [Перенос резервных копий](#moving-backups).
