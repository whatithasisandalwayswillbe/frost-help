# Выбор хранилища

Frost может хранить копии на вашем собственном сервере, на диске, в Permafrost или в S3-совместимом сервисе. Где бы они ни лежали, всё сначала шифруется на вашем компьютере, поэтому тот, кто управляет хранилищем, не может прочитать ваши файлы.

## Варианты

| Хранилище | Подходит для | Что нужно |
| --- | --- | --- |
| [Собственный сервер](#self-hosted) | NAS, домашний сервер или VPS, которым вы управляете | Доступ по SSH |
| [Локальный диск](#local-drive) | USB-диск или второй диск | Диск, подключённый во время копирования |
| [Permafrost](#permafrost) | Хостинговое хранилище, созданное для Frost | Один ключ доступа |
| [Облачные провайдеры](#cloud-providers) | Amazon S3, Cloudflare R2, Backblaze B2 или Wasabi | Бакет и ключи к нему |
| [Другие S3-совместимые хранилища](#other-s3) | S3-сервер, которым вы управляете, например Ceph или SeaweedFS, или другой S3-сервис | Бакет и ключи к нему |

С собственным сервером или локальным диском копии остаются на оборудовании, которым вы управляете, без учётных записей где-либо. Permafrost и облачные провайдеры хранят их вне дома, и своё оборудование обслуживать не нужно.

## Условная запись

Frost нужно хранилище, которое умеет создавать файл за один шаг и только если его имя свободно. Это не даёт двум компьютерам перезаписывать служебные записи копий друг друга. Мастер настройки проверяет это при подключении и не принимает хранилище, которое проверку не проходит. Если хранилище этого не поддерживает, другие ключи или настройки не помогут.

| Хранилище | Условная запись |
| --- | --- |
| Собственный сервер | Поддерживается серверами OpenSSH, на файловых системах с жёсткими ссылками, например ext4, Btrfs, XFS, ZFS, APFS и NTFS |
| Локальный диск | Поддерживается на NTFS, APFS, ext4, Btrfs и XFS. Другие файловые системы должны пройти проверку мастера |
| Permafrost | Поддерживается |
| Amazon S3 | [Описана в документации](https://docs.aws.amazon.com/AmazonS3/latest/userguide/conditional-writes.html) |
| Cloudflare R2 | [Описана в документации](https://developers.cloudflare.com/r2/api/s3/api/) |
| Ceph | Реализована в сервере. Ваша версия должна пройти проверку мастера |
| SeaweedFS | [Описана в документации](https://github.com/seaweedfs/seaweedfs/wiki/S3-Conditional-Operations). Ваша версия должна пройти проверку мастера |
| MinIO | Реализована в сервере, который больше не поддерживается. Ваша версия должна пройти проверку мастера |
| Backblaze B2 | Не подтверждена. В [справке по загрузке](https://www.backblaze.com/apidocs/s3-put-object) нет `If-None-Match` |
| Wasabi | Не подтверждена. [Справка по API](https://docs.wasabi.com/apidocs/operations-on-objects) не подтверждает поддержку |
| Garage | Не поддерживается, по словам сопровождающего |

Сведения об S3-сервисах проверены по документации и исходному коду каждого проекта в октябре 2026 года, без реальных тестов. Решающее слово за проверкой самого мастера.

## Что учесть

- **Копия вне дома.** Диск или сервер дома может погибнуть при том же пожаре или краже, что и компьютер. Сервер в другом месте, Permafrost или облачный провайдер не пострадают. Храните вторую независимую копию всего незаменимого в другом месте.
- **Стоимость восстановления.** Некоторые облачные провайдеры берут плату за скачивание. Полное восстановление скачивает всё, а каждая выборочная проверка скачивает небольшую выборку.
- **Архивные классы хранения.** Frost читает блоки напрямую, поэтому не переносите его объекты в архивный класс, из которого данные нужно сначала извлекать.
- **Удаление и истечение срока.** Frost никогда не удаляет ваши копии. Не добавляйте правила жизненного цикла или задачи очистки, которые удаляют файлы из его папки или ограничивают срок их хранения: снимки используют общие блоки.
- **Ограниченный доступ.** Дайте Frost ключ доступа, который открывает только его собственный бакет, или учётную запись на сервере, которая не может изменить ничего другого, что вам важно.
