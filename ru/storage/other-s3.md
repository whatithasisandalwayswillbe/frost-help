# Другие S3-совместимые хранилища

Подойдёт S3-сервер, которым вы управляете сами, например Ceph или SeaweedFS, или любой другой сервис, работающий по протоколу S3, для которого в мастере нет готовой настройки. Он должен поддерживать условную запись, и мастер это проверяет. Подробнее в разделе [Выбор хранилища](#choosing-storage).

Если вы хотите делать копии на своём компьютере, не обслуживая S3-сервер, проще выбрать [Собственный сервер](#self-hosted). Ему нужен только SSH.

## В мастере настройки

Выполните `frost init`, выберите **S3-compatible**, затем **Other S3-compatible**.

| Вопрос мастера | Ответ |
| --- | --- |
| What is the S3 endpoint? | Имя хоста из документации сервера или провайдера. Имя хоста без `https://` означает HTTPS |
| Which region? | Только если сервер или провайдер его требует. Иначе оставьте пустым |
| What is the bucket name? | Имя бакета, точно как при создании. Бакет должен уже существовать |
| Paste the Access Key ID. | Из консоли сервера или провайдера |
| Paste the Secret Access Key. | Из консоли сервера или провайдера |

frost хранит копии в папке `frost` внутри бакета.

## Серверы, которыми вы управляете

| Сервер | Что нужно знать |
| --- | --- |
| Ceph | Его RADOS Gateway поддерживает условную запись. Укажите мастеру адрес и порт шлюза |
| SeaweedFS | Его S3-шлюз описывает условную запись в документации. Укажите мастеру его адрес, например `http://<server>:8333` |
| MinIO | Поддерживает условную запись, но больше не поддерживается разработчиками, поэтому исправлений не получает. Уже работающий сервер подойдёт, если пройдёт проверку мастера. Укажите мастеру его адрес, например `https://<server>:9000` |
| Garage | Не поддерживает условную запись, поэтому frost не может с ним работать |

Заранее создайте бакет и ключ доступа средствами сервера.

## Сервер без TLS

Для сервера на своём компьютере или в своей сети укажите эндпоинт с `http://`, например `http://localhost:9000`. Тогда TLS выключается для всех запросов, поэтому делайте так только в сети, которой доверяете. Значение `true` в `storage.s3.insecure` выбирает HTTP, если в эндпоинте не указан протокол. Явно указанное `https://` или `http://` имеет приоритет.

## Папка внутри бакета

frost хранит всё в одной папке внутри бакета, по умолчанию `frost`. Полноэкранный мастер о ней не спрашивает.

Чтобы после завершения настройки, но до первой копии использовать другую папку или корень бакета:

1. Выполните `frost config edit` и измените `prefix` в разделе `[storage.s3]`. Оставьте значение пустым, чтобы использовать корень бакета. frost предупредит, что копий там пока нет. Введите `yes`, чтобы всё равно сохранить.
2. Снова выполните `frost init`. Экран проверки предупредит, что так начнётся отдельный набор копий. Нажмите `[s]`, чтобы продолжить.

Если копии у вас уже есть, вместо этого перенесите их, как описано в разделе [Перенос резервных копий](#moving-backups).
