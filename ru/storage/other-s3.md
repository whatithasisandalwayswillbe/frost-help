# Другие S3-совместимые хранилища

Подойдёт любой другой сервис, работающий по протоколу S3, например MinIO, Ceph или провайдер, для которого в мастере нет отдельного пункта. Он обязательно должен поддерживать условную запись. Подробнее в разделе [Выбор хранилища](#choosing-storage).

## В мастере настройки

Выполните `frost init` и выберите **Other S3-compatible**.

| Вопрос мастера | Ответ |
| --- | --- |
| What's the S3 endpoint? | Имя хоста из документации провайдера. Имя хоста без `https://` означает HTTPS |
| Which region? | Только если провайдер его требует. Иначе оставьте пустым |
| What's the bucket called? | Имя бакета, точно как при создании. Бакет должен уже существовать |
| Paste the access key ID. | Из консоли провайдера |
| Paste the secret access key. | Из консоли провайдера |

frost хранит копии в папке `frost` внутри бакета.

## Сервер без TLS

Для тестового сервера на своём компьютере или в своей сети укажите эндпоинт с `http://`, например `http://localhost:9000`. Тогда TLS выключается для всех запросов, поэтому делайте так только в сети, которой доверяете. Значение `true` в `storage.s3.insecure` даёт тот же результат.

## Папка внутри бакета

frost хранит всё в одной папке внутри бакета, по умолчанию `frost`. Полноэкранный мастер о ней не спрашивает.

Чтобы до первой копии использовать другую папку или корень бакета:

1. Выполните `frost config edit` и измените `prefix` в разделе `[storage.s3]`. Оставьте значение пустым, чтобы использовать корень бакета. frost предупредит, что копий там пока нет. Введите `yes`, чтобы всё равно сохранить.
2. Снова выполните `frost init`. Экран проверки предупредит, что так начнётся отдельный набор копий. Нажмите `[s]`, чтобы продолжить.

Если копии у вас уже есть, вместо этого перенесите их, как описано в разделе [Перенос резервных копий](#moving-backups).

## MinIO

Сервер MinIO поддерживает условную запись, но ваша версия должна пройти проверку мастера. Создайте бакет и ключ доступа в консоли MinIO, затем укажите мастеру адрес и порт своего сервера MinIO, например `https://<server>:9000`.
