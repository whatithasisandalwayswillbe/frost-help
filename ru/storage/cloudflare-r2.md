# Cloudflare R2

Резервное копирование в бакет Cloudflare R2. R2 поддерживает условную запись, которая нужна frost.

## Перед началом

1. Создайте бакет R2 в панели управления Cloudflare.
2. Запишите идентификатор учётной записи. Он указан на обзорной странице R2: 32 буквы и цифры.
3. Создайте токен API: R2 > Manage R2 API Tokens > Create API token, с правами Object Read & Write. По возможности ограничьте его своим бакетом.

## В мастере настройки

Выполните `frost init` и выберите **Cloudflare R2**.

| Вопрос мастера | Ответ |
| --- | --- |
| What's your Cloudflare account ID? | Идентификатор из 32 символов с обзорной страницы R2 |
| What's the bucket called? | Имя бакета, точно как при создании |
| Paste the Access Key ID. | Access Key ID нового токена API |
| Paste the Secret Access Key. | Показывается один раз, рядом с Access Key ID |

frost подключается к `<account-id>.r2.cloudflarestorage.com` с регионом `auto` и хранит копии в папке `frost` внутри бакета.

## Полезно знать

Не добавляйте правила жизненного цикла, которые удаляют объекты из папки frost или ограничивают срок их хранения. Снимки используют общие блоки, и удаление одного объекта может испортить сразу многие снимки.
