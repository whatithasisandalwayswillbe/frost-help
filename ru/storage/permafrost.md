# Permafrost

Permafrost представляет собой хостинговое хранилище, созданное для frost. Для подключения хватает одного ключа доступа, без настройки бакета, региона или эндпоинта.

Копии шифруются на вашем компьютере до отправки, как и с любым другим хранилищем. Permafrost не может их прочитать.

## Как получить ключ

1. Выполните `frost init` и выберите **Permafrost**.
2. Выберите **I don't have a key yet** (ключа пока нет). frost откроет в браузере страницу, где можно получить ключ.
3. Когда ключ будет у вас, страница передаст его обратно frost, и тот сразу его сохранит. Даже если после этого выйти из мастера, ключ не потеряется.

Если браузер не открылся, перейдите на [getfro.st/perma](https://getfro.st/perma) сами, а затем нажмите `[p]` в мастере и вставьте полученный ключ. Если получить ключ не удалось, нажмите `[r]`, чтобы попробовать ещё раз, или `[p]`, чтобы вставить ключ. frost ждёт до 25 минут.

Если ключ у вас уже есть, выберите **I have a key** (ключ есть) и вставьте его.

## Как ключ попадает в frost

Пока frost ждёт, он слушает адрес `127.0.0.1`, до которого может достучаться только ваш компьютер. Он передаёт странице случайное значение и принимает только ключ, который вернулся с тем же значением, поэтому никакая другая страница не сможет подсунуть frost свой ключ.

Страница также показывает вам ключ, чтобы его можно было скопировать в frost самостоятельно, например если браузер открыт на другом компьютере.

## Отклонённые ключи

Если Permafrost перестанет принимать ваш ключ доступа, каждая команда будет останавливаться с ошибкой, которая об этом сообщает. Выполните `frost init` и заново настройте хранилище, чтобы получить рабочий ключ.

| Сообщение мастера | Что сделать |
| --- | --- |
| Permafrost didn't accept that access key | Проверьте, что скопировали его целиком. Возможно, срок его действия истёк |
| That access key can't store backups | Проверьте его права в своей учётной записи Permafrost |
| your Permafrost storage is full | В учётной записи не осталось места. Загляните в свою учётную запись Permafrost |

## Собственный сервер

Любой может запустить сервер, поддерживающий [API Permafrost](https://github.com/whatithasisandalwayswillbe/frost/blob/main/docs/PERMAFROST.md). Чтобы им пользоваться, укажите его адрес:

```sh
frost config set storage.permafrost.url https://<your-server>
```

Адрес должен начинаться с `https://`. Исключение составляет только сервер на вашем собственном компьютере, например `http://localhost:8080`. Оставьте настройку пустой, чтобы использовать сервер Permafrost по умолчанию.
