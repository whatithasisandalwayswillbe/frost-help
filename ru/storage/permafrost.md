# Permafrost

Permafrost представляет собой хостинговое хранилище, созданное для Frost. Для подключения хватает одного ключа доступа, без настройки бакета, региона или эндпоинта.

Копии шифруются на вашем компьютере до отправки, как и с любым другим хранилищем. Permafrost не может их прочитать.

Управлять аккаунтом Permafrost можно на [getfro.st/perma/portal](https://getfro.st/perma/portal). В браузере снимков нажмите `[h]`, затем `[p]`, чтобы открыть его. Это сочетание доступно только для стандартного сервиса Permafrost.

## Как получить ключ

1. Выполните `frost init` и выберите **Permafrost**.
2. Выберите **I don't have a key yet** (ключа пока нет). Frost откроет [getfro.st/perma](https://getfro.st/perma) в браузере. Если браузер не открылся, перейдите туда сами.
3. Получите там ключ и скопируйте его.
4. Вставьте его в мастер.

Если ключ у вас уже есть, выберите **I have a key** (ключ есть) и вставьте его.

## Как получить новый ключ

Если вы потеряли ключ, перейдите на [getfro.st/perma/recover](https://getfro.st/perma/recover) и введите адрес электронной почты, с которым получали ключ. В письме, которое придёт, будет ссылка на новый ключ. Новый ключ заменяет старый, и старый перестаёт работать на всех компьютерах.

На каждом компьютере, который использует Permafrost, замените ключ на новый:

```sh
frost config set storage.permafrost.token <new key>
```

Пока Permafrost не принимает загрузки, `frost config set` не может выполнить проверку хранилища. Вместо него используйте `frost config edit` и впишите ключ в `token` в разделе `[storage.permafrost]`.

## Занятое место

`frost status` показывает, сколько места в Permafrost вы занимаете. Когда Permafrost нужно что-то сообщить, например что хранилище почти заполнено, `frost status` и `frost backup` показывают это как предупреждение. Подробнее в разделе [Проверка резервных копий](#checking-backups).

## Когда Permafrost отказывает

Ошибки Permafrost объясняют причину. Команды, обращающиеся к резервным копиям, останавливаются с этим сообщением.

| Что вы видите | Что это значит |
| --- | --- |
| the Permafrost access key was rejected | Ключ неверный, его заменил более новый ключ или учётная запись закрыта. В сообщении сказано, что именно. Используйте самый новый ключ или получите новый |
| uploads are paused | Permafrost пока не принимает новые резервные копии. Восстановление по-прежнему работает. В сообщении сказано, почему, до какого срока и что делать |
| your Permafrost storage is full | Загрузка не помещается. В сообщении сказано, сколько вы храните и что делать |

В мастере первые два сообщения выглядят как «Permafrost didn't accept that access key» и «Permafrost won't store backups with that access key», а после них следует та же причина.

## Совместимый сервер

Вместо сервера по умолчанию Frost может работать с любым сервером, поддерживающим [API Permafrost](https://github.com/whatithasisandalwayswillbe/frost/blob/main/docs/PERMAFROST.md). Этот вариант для тех, у кого уже есть такой сервер. Чтобы делать копии на своём компьютере, вариант [Собственный сервер](#self-hosted) требует только SSH.

Совместимый сервер должен соблюдать правила API для объектов и ошибок, включая отказ от пустых загрузок. Если сервер занят, Frost автоматически повторяет запрос.

Перед первой настройкой создайте файл `config.toml` в папке конфигурации Frost, указанной в разделе [Файлы и папки](#files-and-folders), с такими настройками. Замените адрес на адрес своего сервера:

```toml
[storage]
backend = "permafrost"

[storage.permafrost]
url = "https://<your-server>"
```

Затем выполните `frost init`, выберите Permafrost, вставьте ключ доступа, выберите папки и сохраните настройки. Если сервер пустой, мастер создаст репозиторий.

Если Frost уже настроен, через `frost config edit` измените тип хранилища и адрес сервера вместе в существующем файле. Подтвердите предупреждение, если новый сервер пустой, введите `yes`, чтобы сохранить, а затем снова выполните `frost init`. Команда `frost config set` не принимает пустое место назначения, поэтому подготовить новый сервер с её помощью нельзя.

Адрес должен начинаться с `https://`. Исключение составляет только сервер на вашем собственном компьютере, например `http://localhost:8080`. Оставьте настройку пустой, чтобы использовать сервер Permafrost по умолчанию, `https://permafrost.wihiaawb.com`.
