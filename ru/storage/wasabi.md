# Wasabi

Резервное копирование в бакет Wasabi.

> Документация Wasabi не подтверждает, что он поддерживает условную запись, которая нужна frost. Мастер настройки проверяет это при подключении. Если проверка не пройдена, выберите другого провайдера. Подробнее в разделе [Выбор хранилища](#choosing-storage).

## Перед началом

1. Создайте бакет в консоли Wasabi и запишите его регион, например `us-east-1` или `eu-central-1`.
2. Создайте ключ доступа: Access Keys > Create New Access Key. По возможности используйте пользователя с доступом только к этому бакету.

## В мастере настройки

Выполните `frost init` и выберите **Wasabi**.

| Вопрос мастера | Ответ |
| --- | --- |
| Which region is the bucket in? | Регион бакета, например `us-east-1` |
| What's the bucket called? | Имя бакета, точно как при создании |
| Paste the access key. | Созданный вами ключ доступа |
| Paste the secret key. | Показывается один раз, при создании ключа |

frost подключается к `s3.<region>.wasabisys.com` и хранит копии в папке `frost` внутри бакета.

## Полезно знать

Не добавляйте правила жизненного цикла, которые удаляют объекты из папки frost. Снимки используют общие блоки, и удаление одного объекта может испортить сразу многие снимки.
