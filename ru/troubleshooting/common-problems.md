# Частые проблемы

На этой странице собраны самые частые сообщения и проблемы. Каждый заголовок повторяет то, что пишет frost, или то, что вы замечаете.

## «frost isn't set up yet, run `frost init`»

frost не находит `config.toml`. Выполните `frost init`. Если вы используете `--config-dir` или `FROST_CONFIG_DIR`, проверьте, что они указывают на нужную папку.

## «no key on this machine»

Файла ключа нет. Если на этом компьютере хранилище уже настроено, выполните `frost key import` и введите фразу восстановления. Иначе выполните `frost init`.

## «a backup or restore is already running»

Ваши копии использует другой процесс frost, обычно копирование по расписанию. Дождитесь его завершения и попробуйте снова. Удаление файла блокировки frost не остановит другой процесс.

## «the key on this machine doesn't match»

В хранилище лежат копии, сделанные другим ключом. Выполните `frost key verify` и введите записанную фразу, чтобы понять, какой это ключ. Если ключ тот, что нужен, выполните с ним `frost key import`.

## frost не находит копии

Сообщения вроде «has no frost repository» значат, что копий нет там, где их ищет frost. В ошибке указано, где их открывали в последний раз и как к ним вернуться. Подробнее в разделе [Перенос резервных копий](#moving-backups).

## Мастер не может подключиться

Мастер объясняет проблему и возвращает вас к ответу, который скорее всего в ней виноват.

| Сообщение мастера | Что проверить |
| --- | --- |
| That access key ID wasn't recognised | Что вы скопировали идентификатор ключа доступа целиком |
| The secret key doesn't match the access key ID | Что вы скопировали секретный ключ целиком и что он относится к этому идентификатору |
| There's no bucket with that name | Имя бакета, или сначала создайте бакет |
| That key doesn't have the bucket permissions frost needs | Что ключ может читать, перечислять, записывать и удалять объекты в бакете |
| The bucket is in a different region | Регион или эндпоинт |
| Can't find ... | Адрес и подключение к интернету |
| Nothing answered at that address | Адрес и порт |
| The server's certificate isn't valid for that address | Адрес и то, что сертификат сервера к нему подходит |
| the storage didn't answer in time | Подключение к интернету, затем попробуйте снова |

## «This storage doesn't support conditional writes»

Ваш провайдер не поддерживает функцию, без которой frost не может уберечь компьютеры от перезаписи служебных записей копий друг друга. Другие ключи или настройки не помогут. Выберите другого провайдера. Подробнее в разделе [Выбор хранилища](#choosing-storage).

## «the Permafrost access key was rejected»

Ключ, возможно, неверный или просроченный. Выполните `frost init` и заново настройте хранилище, чтобы получить рабочий ключ. Подробнее в разделе [Permafrost](#permafrost).

## Копия не может прочитать папку

В macOS дело обычно в разрешениях конфиденциальности. В ошибке сказано, что нужно разрешить. Подробнее в разделе [Разрешения macOS](#macos-permissions). В других системах проверьте, что у вашего пользователя есть право читать папку.

## Файлы с пометкой «couldn't be read»

frost пропустил эти файлы и сохранил остальное. Обычные причины: нет прав на чтение, файлы удалили во время копирования, а в macOS ещё и файлы, которые iCloud хранит только в облаке.

## Файлы, которые «kept changing while they were read»

Во время копирования какая-то программа писала в эти файлы, поэтому снимок сохранил их прежнюю копию. Закройте программу и сделайте копию снова или дождитесь следующей копии.

## Папка помечена «not found»

Папки из списка не оказалось на месте, поэтому frost скопировал остальное. Снова подключите диск или, если папка переехала, обновите список через `frost init`.

## «scheduled job is missing»

Задание по расписанию удалили или выключили. Верните его командой `frost config set schedule.enabled true`.

## Копирование по расписанию не запускается

- Посмотрите строку «next backup» в `frost status`.
- В macOS проверьте переключатель frost в разделе «Системные настройки > Основные > Объекты входа и расширения» (System Settings > General > Login Items & Extensions). Он называется Node.js Foundation.
- В Windows для копирования по расписанию нужно войти в систему. При работе от батареи оно не запускается.
- С cron или Планировщиком заданий копия, назначенная на время, когда компьютер был выключен или спал, пропускается.
- Загляните в журнал. Подробнее в разделе [Автоматическое резервное копирование](#scheduling).

## «verification failed»

Выборочная проверка нашла в хранилище недостающие или повреждённые данные. Подробнее в разделе [Проверка резервных копий](#checking-backups).

## «can't restore beside the originals»

Папку рядом с оригиналами использовать нельзя, часто потому, что снимок сделан на другом компьютере. Используйте вместо этого `--to <dir>`. Подробнее в разделе [Восстановление файлов](#restoring).

## «can't overwrite the originals»

Снимок сделан на компьютере другого типа, или путь к оригиналам проходит через ссылку, которой frost не доверяет. Используйте вместо этого `--beside` или `--to <dir>`.

## frost не находит нужный снимок

| Что пишет frost | Что попробовать |
| --- | --- |
| no snapshot at or before ... | Более позднее время. В сообщении указан самый старый снимок |
| "maple" matches 2 snapshots, use more of the ID | Больше символов идентификатора, например `maple-absurd` |
| can't read "..." as a snapshot ID or time | Кавычки вокруг времени с пробелами, например `"3 days ago"` |

## frost не может обновиться сам

frost установлен менеджером пакетов, в его папку нельзя писать или он собран из исходного кода. Подробнее в разделе [Обновление frost](#updating).

## Установщик останавливается

| Что пишет установщик | Что сделать |
| --- | --- |
| need OpenSSH 8.1+ to verify the frost release signature | Установите или обновите OpenSSH. В Windows он входит в Git for Windows |
| checksums.txt isn't signed by the frost release key. Don't install this. | Не устанавливайте. Попробуйте позже и [сообщите о проблеме](#getting-help), если она повторяется |
| checksum mismatch | Загрузка повреждена. Запустите установщик снова |
| 32-bit ARM isn't supported by the bundled runtime | Для этого компьютера пакета frost нет |
