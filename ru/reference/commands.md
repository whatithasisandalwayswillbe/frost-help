# Команды

У frost восемь команд. `frost -h` перечисляет их все вместе со всеми параметрами.

## Общие параметры

Работают с любой командой:

| Параметр | Что делает |
| --- | --- |
| `--config-dir <dir>` | Использует другую папку конфигурации |
| `-h`, `--help` | Показывает справку со всеми командами и параметрами |
| `-v`, `--version` | Показывает версию frost. Указывается перед командой |

## frost init

Настраивает frost: что копировать, куда и как часто. Запустите снова, чтобы просмотреть или изменить настройки. Подробнее в разделе [Настройка frost](#setting-up).

```sh
frost init
```

## frost backup

Создаёт резервную копию прямо сейчас. Подробнее в разделе [Резервное копирование](#backing-up).

```sh
frost backup [--dry-run] [--path <dir>] [--exclude <pattern>] [--no-verify]
```

| Параметр | Что делает |
| --- | --- |
| `-n`, `--dry-run` | Показывает, что было бы отправлено, ничего не отправляя |
| `--path <dir>` | Копирует эту папку вместо обычных. Можно повторять |
| `--exclude <pattern>` | Дополнительно исключает файлы, подходящие под шаблон. Можно повторять |
| `--no-verify` | Пропускает выборочную проверку после копирования |

## frost restore

Возвращает файлы из снимка. Без аргументов открывает обозреватель снимков. Подробнее в разделе [Восстановление файлов](#restoring).

```sh
frost restore [snapshot] [paths...] --beside | --to <dir> | --overwrite
```

| Параметр | Что делает |
| --- | --- |
| `--beside` | Восстанавливает в новую папку рядом с оригиналами |
| `--to <dir>` | Восстанавливает в новую папку внутри указанной |
| `--overwrite` | Восстанавливает поверх оригиналов, заменяя то, что там лежит. Сначала спрашивает |
| `-y`, `--yes` | Не спрашивает перед перезаписью |

## frost status

Показывает последние снимки, расписание и состояние копий. Подробнее в разделе [Проверка резервных копий](#checking-backups).

```sh
frost status [--verify] [--all]
```

| Параметр | Что делает |
| --- | --- |
| `--verify` | Сначала выполняет новую проверку |
| `-a`, `--all` | Показывает все снимки, а не только 10 последних |

## frost browse

Открывает обозреватель снимков. Подробнее в разделе [Обозреватель снимков](#snapshot-browser).

```sh
frost browse
```

## frost config

Читает или меняет настройки без повторного запуска мастера. Подробнее в разделе [Настройки](#settings).

```sh
frost config [--show-secrets]
frost config get <key> [--show-secrets]
frost config set <key> <value...>
frost config edit [editor]
```

| Параметр | Что делает |
| --- | --- |
| `--show-secrets` | Показывает учётные данные полностью, не скрывая их |

## frost key

Показывает, проверяет или импортирует фразу восстановления. Подробнее в разделе [Фраза восстановления](#recovery-phrase).

```sh
frost key show
frost key verify
frost key import
```

## frost update

Обновляет frost до последней версии. Подробнее в разделе [Обновление frost](#updating).

```sh
frost update [--check]
```

| Параметр | Что делает |
| --- | --- |
| `--check` | Только сообщает, есть ли версия новее |

## Коды завершения

frost завершается с кодом `0`, если команда выполнена успешно, и с кодом `1` при любой ошибке. Ошибкой считается и копия или `frost status --verify`, проверка которых нашла проблему, поэтому скрипты могут проверять результат:

```sh
frost status --verify || echo "frost check failed" >&2
```
