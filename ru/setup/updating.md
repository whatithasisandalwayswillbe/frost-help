# Обновление frost

frost обновляется сам. По умолчанию он устанавливает новые версии после копирования по расписанию.

## Обновить сейчас

```sh
frost update
```

frost находит последнюю версию, проверяет её подпись и контрольную сумму и убеждается, что новая версия запускается, прежде чем на неё переключиться. Ваши настройки, ключ и копии не затрагиваются.

Чтобы только проверить, есть ли версия новее:

```sh
frost update --check
```

`frost update` никогда не устанавливает предварительные версии и версии старше вашей.

## Автоматическое обновление

После копирования по расписанию frost не чаще раза в 20 часов проверяет, не вышла ли новая версия, и устанавливает её так же, как `frost update`. Если проверка или установка не удалась, копия из-за этого не считается неудачной.

`frost status` показывает, как настроены обновления и удалось ли последнее. Это же видно на экране настроек в обозревателе снимков.

Чтобы узнавать о новых версиях, но не устанавливать их автоматически:

```sh
frost config set update.auto false
```

Тогда `frost status` будет сообщать о выходе новой версии, а устанавливаться ничего не будет, пока вы не выполните `frost update`.

> Автоматические обновления выполняются только после копирования по расписанию. Если автоматическое копирование выключено, frost вообще не проверяет обновления в фоне.

## Когда frost не может обновиться сам

| Когда | Что сделать |
| --- | --- |
| frost установлен менеджером пакетов (Homebrew, Nix, Snap, Scoop или системным пакетом) | Обновите его этим менеджером пакетов |
| У вас нет права записи в папку приложения frost | Переустановите его установщиком от имени своего пользователя |
| frost собран из исходного кода | Соберите его заново или установите версию установщиком |

Если обновление прервалось на середине, запустите установщик ещё раз. Он восстановит установку.
