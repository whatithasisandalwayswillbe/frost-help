# Резервное копирование

`frost backup` сразу создаёт резервную копию ваших папок. Отправляется только то, что изменилось с прошлой копии.

## Создать копию

```sh
frost backup
```

frost показывает, что изменилось, сколько отправлено и чем закончилась выборочная проверка:

```text
┌  backup  s3://my-backups/frost/
│
│  changes      3 added, 1 changed
│  files        1,204 (2.1 GB)
│  new data     14.2 MB in 9 chunks (9.8 MB uploaded after compression)
│  verified     ok, 21 random objects re-downloaded and checked
│
└  Saved snapshot maple-absurd-3f1c
```

Файл считается изменённым, если поменялись его содержимое, размер, права доступа или время изменения. Изменение одного лишь времени изменения папки не считается, потому что временные файлы меняют его постоянно.

Если ничего не изменилось, frost не сохраняет новый снимок:

```text
┌  backup  s3://my-backups/frost/
│
│  files        1,204 (2.1 GB)
│  verified     ok 3h ago, 21 objects checked
│
└  Already backed up. Nothing has changed since snapshot maple-absurd-3f1c, saved 3h ago.
```

Если автоматическое копирование включено, запускать эту команду самому придётся редко. Подробнее в разделе [Автоматическое резервное копирование](#scheduling).

## Посмотреть заранее

```sh
frost backup --dry-run
```

Пробный запуск перечисляет все файлы с новыми данными для отправки и общий объём, но ничего не отправляет и не сохраняет снимок. `-n` означает то же, что `--dry-run`.

## Параметры

| Параметр | Что делает |
| --- | --- |
| `-n`, `--dry-run` | Показывает, что было бы отправлено, ничего не отправляя |
| `--path <dir>` | Копирует эту папку вместо обычных. Повторите, чтобы добавить ещё папки |
| `--exclude <pattern>` | Дополнительно исключает этот шаблон, только в этот раз. Повторите, чтобы добавить ещё шаблоны |
| `--no-verify` | Пропускает выборочную проверку после копирования |

Чтобы изменить папки, которые копируются каждый раз, снова запустите `frost init` или загляните в раздел [Настройки](#settings).

## Что копируется

frost копирует обычные файлы, папки и символические ссылки вместе с правами доступа и временем изменения.

- Символическая ссылка сохраняется как сама ссылка, а не как файл, на который она указывает.
- Файлы с жёсткими ссылками копируются и восстанавливаются как отдельные файлы.

frost не копирует:

- Всё, что есть в списке исключений. Подробнее в разделе [Исключение файлов](#excluding-files).
- Сокеты, устройства и каналы.
- Владельцев файлов, ACL и расширенные атрибуты.
- В macOS файлы, которые iCloud хранит только в облаке. frost их не скачивает, а пропускает и выводит в списке.
- Файлы `.frost-partial-...`, оставшиеся после прерванного восстановления.

## Если что-то пошло не так

| Что произошло | Что делает frost |
| --- | --- |
| Файл или папку не удаётся прочитать: нет прав, объект удалили во время копирования или он есть только в iCloud | Пропускает и выводит в списке. Снимок всё равно сохраняется, а `frost status` показывает, сколько элементов пропущено |
| Папки из списка нет на месте, например она на отключённом диске | Пропускает её и копирует остальное. `frost backup` и `frost status` называют отсутствующую папку |
| Нет ни одной папки из списка или одна есть, но её вообще не удаётся прочитать | Вся копия завершается ошибкой, чтобы копия никогда не выглядела успешной, если ничего не сохранено |
| Файл меняется, пока frost его читает: используемая база данных, диск работающей виртуальной машины, загрузка | Перечитывает его в конце копирования. Если файл всё ещё меняется, снимок сохраняет его прежнюю копию, а frost выводит файл в списке. Файл, который ни разу не удалось скопировать целиком, пропускается |

frost не делает снимков файловой системы или базы данных. Файл, который всё время занят, копируйте, когда программа, которая его использует, закрыта.

В macOS для чтения некоторых папок frost нужно ваше разрешение. Подробнее в разделе [Разрешения macOS](#macos-permissions).

## Выборочная проверка

После копии, которая сохраняет снимок, frost скачивает несколько случайных блоков, по умолчанию 20, и проверяет их. После копии без изменений он проверяет снова, только если прошлой проверке больше суток или она нашла проблему. Если проверка не прошла, копия сообщает об ошибке. Подробнее в разделе [Проверка резервных копий](#checking-backups).

## Прерванные копии

Если копирование оборвалось на середине, например из-за обрыва связи, закрытой крышки ноутбука или `Ctrl+C`, уже отправленное не пропадает. frost отмечает блоки по мере отправки, и следующая копия их пропустит.

## По одной за раз

Резервное копирование или восстановление из командной строки блокирует свой локальный кэш на время работы. Если другой команде нужен этот кэш, frost сообщает "a backup or restore is already running, try again when it's done" (копирование или восстановление уже выполняется, попробуйте после его завершения). Обозреватель снимков снимает блокировку кэша, поэтому его можно держать открытым и восстанавливать файлы, пока идёт копирование. У разных папок кэша и компьютеров отдельные блокировки.
