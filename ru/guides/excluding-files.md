# Исключение файлов

Список исключений не пускает указанные файлы и папки ни в одну копию. В настройках он называется `exclude`.

## Значения по умолчанию

В новом списке есть `.DS_Store`, `Thumbs.db`, `*.tmp`, `*.swp`, `node_modules` и `.cache`. Удалите те, которые хотите копировать.

## Как работают шаблоны

- **Имя или шаблон без косой черты** совпадает с любым файлом или папкой с таким именем, где бы они ни находились. `node_modules` исключает все папки `node_modules` со всем содержимым.
- **Шаблон с косой чертой** задаёт полный путь. Он исключает этот путь и всё, что внутри. `~` обозначает домашнюю папку, например `~/Downloads/Movies`.

В шаблонах можно использовать такие подстановочные знаки:

| Знак | Что совпадает |
| --- | --- |
| `*` | Любое количество символов, кроме `/` |
| `?` | Любой один символ, кроме `/` |
| `[abc]` | Один из перечисленных символов. `[a-z]` задаёт диапазон, а `[^abc]` означает любой символ, кроме перечисленных |
| `\` | Следующий символ как есть, поэтому `\*` совпадает с настоящей `*` |

Шаблоны учитывают регистр, поэтому `*.MOV` не исключает `clip.mov`.

Сами папки из вашего списка никогда не исключаются, исключается только то, что внутри.

## Примеры

| Шаблон | Что исключает |
| --- | --- |
| `*.iso` | Все образы дисков |
| `.git` | Все папки Git |
| `Cache*` | Всё, чьё имя начинается с `Cache` |
| `~/Library/Caches` | Папку кэша в вашей домашней папке macOS |
| `~/Videos/*.mov` | Файлы `.mov`, лежащие прямо в `~/Videos`, но не во вложенных папках |

## Как изменить список

Запустите `frost init` и измените шаг с исключениями или воспользуйтесь `frost config edit`. Можно задать и весь список одной командой, которая заменит текущий:

```sh
frost config set exclude .DS_Store node_modules '*.tmp' '~/Downloads'
```

Берите в кавычки шаблоны с `*` или `~`, чтобы оболочка не раскрыла их раньше времени.

Чтобы исключить что-то только в одной копии:

```sh
frost backup --exclude '*.iso'
```

Исключение не удаляет файлы из уже существующих снимков.
