# Обозреватель снимков

`frost browse` открывает полноэкранный обозреватель снимков. В нём можно просматривать файлы такими, какими они были, сравнивать снимки и восстанавливать выбранное.

```sh
frost browse
```

`frost restore` без аргументов тоже открывает обозреватель. Пока он открыт, копирование по расписанию может выполняться.

## Перемещение

| Клавиша | Что делает |
| --- | --- |
| `[↑]` `[↓]` или `[k]` `[j]` | Перемещение |
| `[pgup]` `[pgdn]` | Перемещение на страницу |
| `[g]` `[G]` | Переход в начало или в конец |
| `[enter]` | Открыть |
| `[esc]` | Назад или закрыть ошибку |
| `[h]` | Показать все клавиши |
| `[s]` | Показать настройки |
| `[v]` | Показать или скрыть отпечаток ключа |
| `[q]` | Выйти |

Экран настроек только для чтения. Меняйте настройки через `frost config set` или `frost config edit`.

## Главный экран

На главном экране видны последняя копия и результат последней проверки. Нажмите `[enter]`, чтобы перейти к снимкам, или `[r]`, чтобы обновить данные.

## Снимки

Снимки идут от новых к старым и сгруппированы по датам. Если окно широкое, рядом со списком появляется панель с подробностями о выделенном снимке: когда и на каком компьютере он сделан, сколько в нём файлов, его размер и сколько новых данных он добавил.

| Клавиша | Что делает |
| --- | --- |
| `[enter]` | Открыть файлы снимка |
| `[d]` | Сравнить с предыдущим снимком |
| `[m]` | Отметить снимок. Затем нажмите `[d]` на другом снимке, чтобы сравнить их |

Сравнение показывает, что было добавлено, удалено и изменено между двумя снимками.

## Файлы

Вы видите папки и файлы точно такими, какими они были в этом снимке.

| Клавиша | Что делает |
| --- | --- |
| `[enter]` | Открыть папку |
| `[←]` | Подняться в родительскую папку |
| `[space]` | Выделить или снять выделение |
| `[a]` | Выделить всё в этой папке или снять выделение |
| `[c]` | Сбросить выделение |
| `[r]` | Восстановить выделенное или, если ничего не выделено, подсвеченный элемент |

## Восстановление

После `[r]` выберите, куда попадут файлы:

| Клавиша | Вариант | Что делает |
| --- | --- | --- |
| `[1]` | New folder beside originals | Восстанавливает в новую папку рядом с оригиналами, как `frost restore --beside` |
| `[2]` | New folder elsewhere | Даёт выбрать папку и восстанавливает в новую папку внутри неё |
| `[3]` | Overwrite original files | Заменяет оригиналы, как `frost restore --overwrite`. Подтвердите клавишей `[y]` |

Прежде чем что-либо записать, frost показывает, куда что попадёт. Нажмите `[enter]`, чтобы восстановить, `[c]`, чтобы сменить папку, или `[esc]`, чтобы отменить. Длинные подтверждения и результаты прокручиваются клавишами `[pgup]` и `[pgdn]`.

"New folder elsewhere" открывает системное окно выбора папки: Finder в macOS, Проводник в Windows и zenity, qarma или matedialog в Linux. При работе через SSH или в Linux без такого окна папку нужно ввести вручную. Нажмите `[t]`, пока окно выбора открыто, чтобы всё равно ввести её вручную.

Когда восстановление закончится, frost покажет результат в Finder, Проводнике или файловом менеджере Linux. Если восстановлен один файл, он будет выделен, иначе откроется папка, в которой лежит всё восстановленное. Через SSH, без графического окружения или при неудачном восстановлении ничего не открывается.

Каждый вариант и то, что происходит при прерванном восстановлении, подробно описаны в разделе [Восстановление файлов](#restoring).
