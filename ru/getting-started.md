# Начало работы

Frost создаёт резервные копии ваших папок в выбранном вами хранилище, от собственного сервера или диска до облачного провайдера, и шифрует всё на вашем компьютере ещё до сохранения. Эта страница проведёт вас от установки Frost до первой резервной копии.

## Что понадобится

- Компьютер Mac, с Linux или с Windows на 64-битном процессоре Intel, AMD или ARM.
- Место для хранения копий: сервер, доступный по SSH, диск, ключ доступа [Permafrost](#permafrost) или S3-совместимый бакет. Варианты сравниваются в разделе [Выбор хранилища](#choosing-storage).
- Окно терминала шириной не меньше 56 столбцов и высотой не меньше 18 строк для полноэкранного мастера настройки.

Заранее устанавливать Node.js или что-либо ещё не нужно. Frost поставляется со своей средой выполнения.

## 1. Установите Frost

В macOS или Linux выполните эту команду в терминале:

```sh
curl -fsSL https://raw.githubusercontent.com/whatithasisandalwayswillbe/frost/main/install/install.sh | sh
```

В Windows выполните эту команду в PowerShell:

```powershell
irm https://raw.githubusercontent.com/whatithasisandalwayswillbe/frost/main/install/install.ps1 | iex
```

Прежде чем что-либо устанавливать, установщик проверяет подпись версии. Об установке через npm и pnpm, установке вручную и параметрах установщика рассказано в разделе [Установка Frost](#installing).

## 2. Настройте

```sh
frost init
```

Мастер настройки задаёт по одному вопросу на экране:

1. **Хранилище.** Где будут лежать копии. Выберите Permafrost, S3-совместимый сервис, собственный сервер или диск и ответьте на вопросы мастера.
2. **Папки.** Что копировать, например `~/Documents`.
3. **Исключения.** Файлы и папки, которые копировать не нужно. Несколько типичных, вроде `node_modules`, уже добавлены.
4. **Расписание.** Как часто Frost делает копии сам, или не делает их вовсе.
5. **Фраза восстановления.** 24 слова, которые открывают доступ к копиям. Запишите их.
6. **Проверка.** Просмотрите всё и нажмите `[s]`, чтобы сохранить.

> Если этот компьютер пропадёт, прочитать копии можно будет только с помощью фразы восстановления. Никто не сможет восстановить её за вас: ни тот, кто хранит ваши копии, ни авторы Frost.

Каждый экран подробно описан в разделе [Настройка Frost](#setting-up).

## 3. Создайте копию

Сначала посмотрите, что отправит первая резервная копия:

```sh
frost backup --dry-run
```

Затем запустите её:

```sh
frost backup
```

Первая копия отправляет всё. Последующие отправляют только изменения. Если вы включили расписание, Frost теперь делает копии сам, и запускать ничего не нужно.

## 4. Проверьте состояние

```sh
frost status
```

`status` показывает последнюю копию, время следующей, результат последней проверки и недавние снимки.

## Как вернуть файлы

Откройте обозреватель снимков, найдите нужное, выделите клавишей `[space]` и нажмите `[r]`:

```sh
frost browse
```

Можно восстановить и из командной строки. Эта команда кладёт копию файла в новую папку рядом с оригиналом:

```sh
frost restore latest ~/Documents/report.pdf --beside
```

Оба способа описаны в разделе [Восстановление файлов](#restoring).
