# 파일 제외

제외 목록에 넣은 파일과 폴더는 어떤 백업에도 들어가지 않습니다. 설정에서는 `exclude`라는 이름입니다.

## 기본값

새 제외 목록에는 `.DS_Store`, `Thumbs.db`, `*.tmp`, `*.swp`, `node_modules`, `.cache`가 들어 있습니다. 백업하고 싶은 항목이 있으면 지우세요.

## 패턴 작성법

- **슬래시가 없는 이름이나 패턴**은 어디에 있든 그 이름의 파일이나 폴더와 일치합니다. `node_modules`는 모든 `node_modules` 폴더와 그 안의 내용을 제외합니다.
- **슬래시가 있는 패턴**은 전체 경로입니다. 그 경로와 그 아래의 모든 것을 제외합니다. `~`는 홈 폴더를 뜻하며, `~/Downloads/Movies`처럼 씁니다.

패턴에는 다음 와일드카드를 쓸 수 있습니다.

| 와일드카드 | 일치하는 것 |
| --- | --- |
| `*` | `/`를 제외한 임의 개수의 문자 |
| `?` | `/`를 제외한 임의의 한 문자 |
| `[abc]` | 나열한 문자 중 하나. `[a-z]`는 범위이고, `[^abc]`는 나열하지 않은 아무 문자입니다 |
| `\` | 다음 문자를 글자 그대로 취급합니다. `\*`는 실제 `*`와 일치합니다 |

패턴은 대소문자를 구분합니다. 그래서 `*.MOV`는 `clip.mov`를 제외하지 않습니다.

목록에 있는 폴더 자체는 절대 제외되지 않고, 그 안의 항목만 제외될 수 있습니다.

## 예시

| 패턴 | 제외하는 것 |
| --- | --- |
| `*.iso` | 모든 디스크 이미지 |
| `.git` | 모든 Git 폴더 |
| `Cache*` | 이름이 `Cache`로 시작하는 모든 항목 |
| `~/Library/Caches` | macOS 홈 폴더의 캐시 폴더 |
| `~/Videos/*.mov` | `~/Videos` 바로 아래에 있는 `.mov` 파일. 하위 폴더 안의 파일은 포함하지 않습니다 |

## 목록 바꾸기

`frost init`을 실행해 "Skip"(제외) 단계에서 바꾸거나 `frost config edit`를 쓰세요. 명령어 하나로 목록 전체를 지정할 수도 있으며, 이때 기존 목록은 대체됩니다.

```sh
frost config set exclude .DS_Store node_modules '*.tmp' '~/Downloads'
```

`*`나 `~`가 들어간 패턴은 셸이 먼저 펼치지 않도록 따옴표로 감싸세요.

한 번의 백업에서만 무언가를 제외하려면 다음을 실행합니다.

```sh
frost backup --exclude '*.iso'
```

제외해도 이미 있는 스냅샷에서 그 항목이 지워지지는 않습니다.
