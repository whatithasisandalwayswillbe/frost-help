# 스냅샷 브라우저

`frost browse`는 전체 화면 스냅샷 브라우저를 엽니다. 당시 모습 그대로 파일을 둘러보고, 스냅샷을 비교하고, 고른 항목을 복원할 수 있습니다.

```sh
frost browse
```

`frost restore`를 인자 없이 실행해도 브라우저가 열립니다. 브라우저가 열려 있는 동안에도 예약된 백업은 실행될 수 있습니다.

## 이동

| 키 | 동작 |
| --- | --- |
| `[↑]` `[↓]` 또는 `[k]` `[j]` | 이동 |
| `[pgup]` `[pgdn]` | 한 페이지씩 이동 |
| `[g]` `[G]` | 맨 위 또는 맨 아래로 이동 |
| `[enter]` | 열기 |
| `[esc]` | 뒤로 가기, 또는 오류 닫기 |
| `[h]` | 모든 키 보기 |
| `[s]` | 설정 보기 |
| `[v]` | 키 지문 보이기 또는 숨기기 |
| `[q]` | 종료 |

설정 화면은 읽기 전용입니다. 설정을 바꾸려면 `frost config set`이나 `frost config edit`를 쓰세요.

## 홈

홈 화면에는 마지막 백업과 최근 점검 결과가 표시됩니다. `[enter]`를 누르면 스냅샷 목록으로 가고, `[r]`을 누르면 새로 고칩니다.

## 스냅샷

스냅샷은 최신순으로, 날짜별로 묶여 표시됩니다. 창이 넓으면 목록 옆 패널에 강조된 스냅샷의 세부 정보가 나옵니다. 만든 시각, 만든 컴퓨터, 파일 수, 크기, 새로 추가된 데이터 양을 볼 수 있습니다.

| 키 | 동작 |
| --- | --- |
| `[enter]` | 스냅샷의 파일 열기 |
| `[d]` | 바로 이전 스냅샷과 비교 |
| `[m]` | 표시하기. 그런 다음 다른 스냅샷에서 `[d]`를 누르면 두 스냅샷을 비교합니다 |

비교하면 두 스냅샷 사이에 추가, 삭제, 수정된 항목이 나열됩니다.

## 파일

그 스냅샷 시점의 폴더와 파일이 그대로 보입니다.

| 키 | 동작 |
| --- | --- |
| `[enter]` | 폴더 열기 |
| `[←]` | 상위 폴더로 이동 |
| `[space]` | 선택 또는 선택 해제 |
| `[a]` | 이 폴더의 모든 항목 선택 또는 선택 해제 |
| `[c]` | 선택 모두 해제 |
| `[r]` | 선택한 항목 복원. 선택한 것이 없으면 강조된 항목을 복원합니다 |

## 복원

`[r]`을 누른 뒤 파일을 복원할 위치를 고릅니다.

| 키 | 선택지 | 동작 |
| --- | --- | --- |
| `[1]` | New folder beside originals | 원본 옆의 새 폴더에 복원합니다. `frost restore --beside`와 같습니다 |
| `[2]` | New folder elsewhere | 폴더를 고르게 한 뒤, 그 안의 새 폴더에 복원합니다 |
| `[3]` | Overwrite original files | 원본을 대체합니다. `frost restore --overwrite`와 같습니다. `[y]`를 눌러 확정합니다 |

무엇이든 쓰기 전에 frost는 각 항목이 어디에 놓일지 보여 줍니다. `[enter]`를 누르면 복원하고, `[c]`를 누르면 폴더를 바꾸고, `[esc]`를 누르면 취소합니다. 긴 확인 화면이나 결과는 `[pgup]`과 `[pgdn]`으로 스크롤합니다.

"New folder elsewhere"를 고르면 시스템의 폴더 선택 창이 열립니다. macOS에서는 Finder, Windows에서는 파일 탐색기, Linux에서는 zenity, qarma, matedialog 중 하나입니다. SSH로 접속했거나 폴더 선택 창이 없는 Linux에서는 폴더를 직접 입력합니다. 선택 창이 열려 있을 때 `[t]`를 누르면 직접 입력으로 바꿀 수 있습니다.

복원이 끝나면 frost는 복원한 항목을 Finder, 파일 탐색기 또는 Linux 파일 관리자에서 보여 줍니다. 파일 하나만 복원했다면 그 파일이 선택된 상태로 보이고, 그렇지 않으면 모든 항목을 담은 폴더가 열립니다. SSH로 접속했거나, 화면이 없거나, 복원에 실패하면 아무것도 열리지 않습니다.

각 선택지에 대한 자세한 설명과 복원이 중단될 때의 동작은 [파일 복원](#restoring)에서 설명합니다.
