# 백업 확인

frost는 백업하는 동안 계속 상태를 점검하고, `frost status`로 그 결과를 보여 줍니다.

## frost status

```sh
frost status
```

```text
┌  frost  v0.1.0  s3://my-backups/frost/  key 6f154dc10058
│
│  last backup  ok 2h ago  maple-absurd-3f1c
│  next backup  ~in 4h  6h via launchd
│  health       ok 21 objects checked 2h ago
│  updates      automatic
│  protected    1,204 files, 2.1 GB, in 3 snapshots
│
├  snapshots
│
│  snapshot             taken                  files         size          new
│  maple-absurd-3f1c    2026-10-08 09:17       1,204       2.1 GB      14.2 MB
│  orbit-velvet-a02e    2026-10-08 03:17       1,201       2.1 GB       3.6 MB
│  canyon-pilot-77b9    2026-10-07 21:17       1,198       2.1 GB       2.1 GB
└
```

첫 줄에는 frost 버전, 스토리지, 키 지문이 표시됩니다. 그 아래 각 줄의 의미는 다음과 같습니다.

| 줄 | 내용 |
| --- | --- |
| last backup | 마지막 백업 시각과 성공 여부. "ok, but" 뒤에는 찾지 못한 폴더, 읽지 못한 항목, 이전 사본을 유지한 사용 중인 파일이 나열됩니다 |
| next backup | 다음 자동 백업 예정 시각. 자동 백업이 꺼져 있으면 그렇다고 표시합니다 |
| health | 최근 표본 검사 결과 |
| updates | 업데이트가 자동인지, 새 릴리스가 나왔는지 |
| protected | 최신 스냅샷의 파일 수와 크기, 그리고 전체 스냅샷 수 |
| missing | 이 컴퓨터가 알고 있었지만 스토리지에서 사라진 스냅샷 |

목록에는 최신 스냅샷 10개가 표시됩니다. `new` 열은 각 스냅샷이 새로 추가한 데이터 양입니다. 모두 보려면 다음을 실행합니다.

```sh
frost status --all
```

## 표본 검사

스냅샷을 저장한 백업이 끝날 때마다 frost는 청크를 무작위로 내려받아 하나씩 복호화하고 ID와 일치하는지 확인합니다. 또한 최신 스냅샷의 파일 목록을 불러와, 필요한 청크를 frost가 모두 알고 있는지도 확인합니다. 새 내용이 없는 백업에서는 마지막 검사가 하루 이상 지났거나 문제를 발견했을 때만 다시 검사합니다.

기본 표본은 청크 20개입니다. 표본을 늘리면 더 많은 문제를 찾지만, 내려받는 양도 늘어납니다.

```sh
frost config set verify.sample 50
```

`0`으로 설정하면 표본 검사가 꺼집니다.

## 지금 확인하기

```sh
frost status --verify
```

새로 표본 검사를 하고, frost가 로컬에 기록한 청크 목록을 스토리지의 모든 내용과 대조합니다. `verify.sample`이 `0`이어도 이 명령어는 청크 20개를 검사합니다. 검사에 실패하면 `1`로 종료하므로, 직접 쓰는 스케줄러에서 실행해 백업과는 다른 주기로 점검할 수 있습니다.

## 검사에 실패했을 때

health 줄에 실패한 내용이 표시됩니다. 대개 스토리지가 청크 일부를 잃었거나 손상시켰다는 뜻입니다.

1. `frost backup`을 실행합니다. 없어진 청크 가운데 데이터가 아직 컴퓨터에 남아 있는 것은 다시 업로드됩니다.
2. `frost status --verify`를 실행해 다시 확인합니다.

컴퓨터에서 이미 사라진 데이터는 다시 업로드할 수 없으며, 그 데이터가 필요한 이전 스냅샷은 완전히 복원할 수 없습니다. 스토리지에 남아 있지만 손상된 청크는 백업이 자동으로 교체하지 않습니다. 제공업체나 별도의 독립적인 백업에서 정상 사본을 되찾은 뒤 다시 확인하세요.

## 사라진 스냅샷

이 컴퓨터가 알고 있던 스냅샷이 스토리지에서 사라지면 `frost status`가 한 번 알려 줍니다. 백업을 옮겼다면 frost에 새 위치를 지정하세요. 자세한 내용은 [백업 옮기기](#moving-backups)를 참고하세요. 그렇지 않다면 스토리지에서 삭제된 것입니다.

> 표본 검사는 백업의 일부만 살펴봅니다. 문제를 일찍 찾아 주지만, 모든 스냅샷이 복원된다는 것을 보장하지는 못합니다. 잃어서는 안 되는 파일은 별도의 독립적인 백업도 함께 두세요.
