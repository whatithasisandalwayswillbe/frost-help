# 시작하기

frost는 원하는 스토리지에 폴더를 백업하며, 업로드하기 전에 모든 내용을 사용자의 컴퓨터에서 암호화합니다. 이 페이지에서는 frost 설치부터 첫 백업까지 안내합니다.

## 준비물

- 64비트 Intel, AMD 또는 ARM 프로세서를 사용하는 Mac, Linux 또는 Windows 컴퓨터.
- 백업을 보관할 곳. [Permafrost](#permafrost) 액세스 키나 [S3 호환 제공업체](#choosing-storage)의 버킷이 필요합니다.
- 전체 화면 설정 도우미를 표시할, 너비 56열 이상, 높이 18행 이상의 터미널 창.

Node.js 등 다른 프로그램을 미리 설치할 필요는 없습니다. frost에는 자체 런타임이 포함되어 있습니다.

## 1. frost 설치하기

macOS나 Linux에서는 터미널에서 다음 명령어를 실행합니다. Windows에서는 Git Bash에서 실행합니다.

```sh
curl -fsSL https://raw.githubusercontent.com/whatithasisandalwayswillbe/frost/main/install/install.sh | sh
```

설치 프로그램은 무엇이든 설치하기 전에 릴리스의 서명부터 확인합니다. 수동 설치와 설치 프로그램 옵션은 [frost 설치](#installing)에서 설명합니다.

## 2. 설정하기

```sh
frost init
```

설정 도우미는 화면마다 한 가지만 묻습니다.

1. **스토리지.** 백업을 보관할 곳입니다. Permafrost나 S3 호환 제공업체를 고르고, 요청하는 키를 붙여 넣습니다.
2. **폴더.** 백업할 폴더입니다. 예를 들면 `~/Documents`입니다.
3. **제외.** 백업하지 않을 파일과 폴더입니다. `node_modules`처럼 흔한 항목 몇 가지는 미리 채워져 있습니다.
4. **일정.** frost가 알아서 백업하는 주기입니다. 끌 수도 있습니다.
5. **복구 문구.** 백업의 잠금을 푸는 24개의 단어입니다. 반드시 적어 두세요.
6. **검토.** 모든 내용을 확인한 다음 `[s]`를 눌러 저장합니다.

> 이 컴퓨터를 잃어버리면 백업을 읽을 수 있는 방법은 복구 문구뿐입니다. 스토리지 제공업체도, frost 개발자도 대신 복구해 줄 수 없습니다.

각 화면은 [frost 설정](#setting-up)에서 자세히 설명합니다.

## 3. 백업하기

먼저 첫 백업에서 무엇이 업로드될지 미리 봅니다.

```sh
frost backup --dry-run
```

그런 다음 실행합니다.

```sh
frost backup
```

첫 백업에서는 모든 내용을 업로드합니다. 그 뒤로는 바뀐 부분만 업로드합니다. 일정을 켰다면 이제 frost가 알아서 백업하므로 따로 실행할 필요가 없습니다.

## 4. 상태 확인하기

```sh
frost status
```

`status`는 마지막 백업, 다음 백업 예정 시각, 최근 점검 결과, 최근 스냅샷을 보여 줍니다.

## 파일 되찾기

스냅샷 브라우저를 열고 필요한 항목을 찾아 `[space]`로 선택한 다음 `[r]`을 누릅니다.

```sh
frost browse
```

명령줄에서 복원할 수도 있습니다. 다음 명령어는 원본 옆에 새 폴더를 만들고 그 안에 파일의 복사본을 넣습니다.

```sh
frost restore latest ~/Documents/report.pdf --beside
```

두 방법 모두 [파일 복원](#restoring)에서 설명합니다.
