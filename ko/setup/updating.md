# frost 업데이트

frost는 스스로 업데이트합니다. 기본적으로 예약된 백업이 끝난 뒤 새 릴리스를 설치합니다.

## 지금 업데이트하기

```sh
frost update
```

frost는 최신 릴리스를 찾아 서명과 체크섬을 확인하고, 새 버전이 제대로 시작되는지 확인한 뒤에 전환합니다. 설정, 키, 백업은 건드리지 않습니다.

새 릴리스가 있는지만 확인하려면 다음을 실행합니다.

```sh
frost update --check
```

`frost update`는 프리릴리스나 지금보다 오래된 버전을 설치하지 않습니다.

## 자동 업데이트

예약된 백업이 끝나면 frost는 하루에 최대 한 번 새 릴리스를 확인하고, `frost update`와 같은 방식으로 설치합니다. 확인이나 설치에 실패해도 백업이 실패하지는 않습니다.

업데이트 설정과 마지막 업데이트의 성공 여부는 `frost status`에서 볼 수 있습니다. 스냅샷 브라우저의 설정 화면에도 표시됩니다.

새 릴리스 소식만 받고 자동으로 설치하지 않으려면 다음을 실행합니다.

```sh
frost config set update.auto false
```

이후에는 새 릴리스가 나오면 `frost status`에서 알려 주고, `frost update`를 실행하기 전까지는 아무것도 설치하지 않습니다.

> 자동 업데이트는 예약된 백업이 끝난 뒤에만 실행됩니다. 자동 백업을 꺼 두면 frost는 백그라운드에서 업데이트를 전혀 확인하지 않습니다.

## frost가 스스로 업데이트할 수 없는 경우

| 상황 | 대신 할 일 |
| --- | --- |
| 패키지 관리자(Homebrew, Nix, Snap, Scoop, 시스템 패키지)로 frost를 설치함 | 그 패키지 관리자로 업데이트합니다 |
| frost의 애플리케이션 폴더에 쓰기 권한이 없음 | 본인 사용자 계정으로 설치 프로그램을 사용해 다시 설치합니다 |
| frost를 소스에서 빌드함 | 다시 빌드하거나, 설치 프로그램으로 릴리스를 설치합니다 |

업데이트가 도중에 멈췄다면 설치 프로그램을 다시 실행하세요. 설치가 복구됩니다.
