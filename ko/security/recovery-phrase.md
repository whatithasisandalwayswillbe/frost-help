# 복구 문구

복구 문구는 암호화 키를 24개의 단어로 적은 것입니다. 백업을 읽을 수 있는 유일한 수단입니다.

> 복구 문구와 컴퓨터를 모두 잃으면 백업도 잃게 됩니다. 스토리지 제공업체도, Permafrost도, frost 개발자도 누구도 되살릴 수 없습니다.

## 안전하게 보관하기

설정 도우미는 키를 만들 때 복구 문구를 보여 줍니다. 종이에 적거나 믿을 수 있는 비밀번호 관리자에 저장하고, 백업하는 컴퓨터가 아닌 다른 곳에 보관하세요.

예약된 백업이 사용자 없이도 실행될 수 있도록, 컴퓨터에도 사본이 하나 있습니다. frost 설정 폴더의 `key` 파일입니다. macOS와 Linux에서는 frost가 사용자 본인만 읽고 쓸 수 있는 권한으로 만듭니다. Windows에서는 사용자 프로필의 권한을 상속합니다. 공유 폴더나 변경된 권한으로 인해 다른 사람에게 노출될 수 있습니다. 이 파일을 읽을 수 있거나 사용자 권한으로 프로그램을 실행할 수 있는 사람은 백업을 읽을 수 있으므로, 디스크 전체 암호화와 화면 잠금을 사용하세요.

백업을 읽으려면 복구 문구와 스토리지 접근 권한이 모두 필요합니다. 스토리지 키도 남에게 알려지지 않게 하세요.

## 보기

```sh
frost key show
```

frost는 먼저 주의 문구를 보여 주고, `show`를 입력한 뒤에만 복구 문구를 표시합니다. 아무도 화면을 보고 있지 않고, 화면을 공유하고 있지 않은지 확인하세요.

## 적어 둔 내용 확인하기

```sh
frost key verify
```

적어 둔 복구 문구를 입력합니다. frost는 그 문구가 유효한지, 이 컴퓨터의 키와 일치하는지, 백업을 열 수 있는지 알려 줍니다. 복구 문구 자체는 절대 출력하지 않습니다. 가끔씩 확인해 두세요.

## 다른 컴퓨터에서 쓰기

`frost init`은 이미 백업이 있는 스토리지에 연결할 때 복구 문구를 묻습니다. 복구 문구를 컴퓨터에 직접 넣으려면 다음을 실행합니다.

```sh
frost key import
```

스토리지가 설정되어 있다면 frost는 먼저 그 문구로 스토리지를 열 수 있는지 확인합니다. 컴퓨터에 이미 다른 키가 있다면 바꾸기 전에 묻습니다. 이전 키로 만든 백업을 복원하려면 이전 복구 문구가 필요합니다.

전체 단계는 [새 컴퓨터에서 복구](#new-computer)를 참고하세요.

## 복구 문구 입력하기

24개 단어를 순서대로, 공백으로 구분해 입력합니다. 대소문자는 상관없습니다. 단어는 2,048개 단어로 된 표준 BIP39 영어 목록에서 나오므로, 철자가 틀리면 frost가 알려 줄 수 있습니다.

| frost의 메시지 | 의미 |
| --- | --- |
| that's 23 words, a recovery phrase has 24 | 단어가 하나 빠졌거나 하나 더 있습니다 |
| word 5, "hapy", isn't a recovery phrase word | 그 단어의 철자가 틀렸습니다 |
| all the words are real, but they don't make a valid phrase | 두 단어의 순서가 바뀌었거나, 한 단어가 다른 실제 단어로 바뀌었습니다 |
| that's a valid phrase, but not the one for these backups | 다른 백업의 복구 문구입니다 |

## 키 지문

지문은 `6f154dc10058` 같은 짧은 ID로, 키를 드러내지 않고 키를 식별합니다. `frost status`에 표시되고, 스냅샷 브라우저에서도 `[v]`를 누르면 보입니다. 지문이 같은 두 컴퓨터는 같은 키를 가지고 있습니다.

## 키 바꾸기

frost는 이미 있는 백업의 키를 바꿀 수 없습니다. 다른 사람이 복구 문구를 봤을 수도 있다면, 그 사람은 스토리지에 접근할 수 있는 한 그 백업을 읽을 수 있습니다. 스토리지 키를 바꾸고 남에게 알려지지 않게 하세요.
