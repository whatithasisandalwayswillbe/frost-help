# 기타 S3 호환 스토리지

MinIO, Ceph, 또는 설정 도우미에 전용 항목이 없는 제공업체처럼 S3 프로토콜을 쓰는 다른 서비스도 사용할 수 있습니다. 단, 조건부 쓰기를 지원해야 합니다. 자세한 내용은 [스토리지 선택](#choosing-storage)을 참고하세요.

## 설정 도우미에서

`frost init`을 실행하고 **Other S3-compatible**을 고릅니다.

| 설정 도우미의 질문 | 답 |
| --- | --- |
| What's the S3 endpoint? | 제공업체 문서에 나온 호스트 이름. `https://` 없이 호스트 이름만 쓰면 HTTPS로 연결합니다 |
| Which region? | 제공업체가 요구할 때만 입력합니다. 그렇지 않으면 비워 둡니다 |
| What's the bucket called? | 만들 때와 똑같은 버킷 이름. 버킷은 미리 만들어 두어야 합니다 |
| Paste the access key ID. | 제공업체 콘솔에서 확인합니다 |
| Paste the secret access key. | 제공업체 콘솔에서 확인합니다 |

frost는 버킷 안의 `frost` 폴더에 백업을 저장합니다.

## TLS를 쓰지 않는 서버

자신의 컴퓨터나 네트워크에서 돌리는 테스트 서버라면 `http://localhost:9000`처럼 `http://`로 시작하는 엔드포인트를 입력합니다. 이렇게 하면 모든 요청에서 TLS가 꺼지므로, 믿을 수 있는 네트워크에서만 쓰세요. `storage.s3.insecure`를 `true`로 설정해도 같은 효과가 있습니다.

## 버킷 안의 폴더

frost는 버킷 안의 폴더 하나에 모든 것을 저장하며, 기본값은 `frost`입니다. 전체 화면 설정 도우미는 이 폴더를 묻지 않습니다.

첫 백업 전에 다른 폴더나 버킷 최상위를 쓰려면 다음과 같이 합니다.

1. `frost config edit`를 실행하고 `[storage.s3]` 아래의 `prefix`를 바꿉니다. 버킷 최상위를 쓰려면 비워 둡니다. frost가 그곳에 아직 백업이 없다고 경고하면, `yes`를 입력해 그대로 저장합니다.
2. `frost init`을 다시 실행합니다. 검토 화면에 별도의 백업을 새로 시작하게 된다는 경고가 나오면, `[s]`를 눌러 진행합니다.

이미 백업이 있다면 대신 백업을 옮기세요. 방법은 [백업 옮기기](#moving-backups)에서 설명합니다.

## MinIO

MinIO 서버는 조건부 쓰기를 지원하지만, 사용하는 버전이 설정 도우미의 테스트를 통과해야 합니다. MinIO 콘솔에서 버킷과 액세스 키를 만든 다음, `https://<server>:9000`처럼 MinIO 서버의 주소와 포트를 설정 도우미에 입력합니다.
