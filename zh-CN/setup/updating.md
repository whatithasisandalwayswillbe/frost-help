# 更新 frost

frost 会自己更新。默认情况下，它会在计划备份之后安装新的发布版本。

## 立即更新

```sh
frost update
```

frost 会找到最新的发布版本，检查它的签名和校验和，并确认新版本能够正常启动，然后才切换过去。你的设置、密钥和备份都不会受到影响。

如果只想看看有没有更新的版本：

```sh
frost update --check
```

`frost update` 永远不会安装预发布版本，也不会安装比你当前版本更旧的版本。

## 自动更新

每次计划备份之后，frost 会检查有没有新的发布版本，每 20 小时最多检查一次，并用与 `frost update` 相同的方式安装。检查或安装失败，都不会导致备份失败。

`frost status` 会显示更新是如何设置的，以及上一次更新是否成功。快照浏览器的设置界面也会显示这些信息。

如果只想收到新版本的通知，而不自动安装：

```sh
frost config set update.auto false
```

之后，有新版本发布时 `frost status` 会告诉你，但在你运行 `frost update` 之前，什么都不会安装。

> 自动更新只在计划备份之后运行。如果关闭了自动备份，frost 根本不会在后台检查更新。

## frost 无法自我更新的情况

| 情况 | 改为这样做 |
| --- | --- |
| frost 是通过包管理器安装的（Homebrew、Nix、Snap、Scoop 或系统自带的软件包） | 用那个包管理器来更新 |
| 你没有 frost 应用程序文件夹的写入权限 | 以你自己的用户身份，用安装程序重新安装 |
| frost 是从源代码构建的 | 重新构建，或者用安装程序安装一个发布版本 |

如果更新中途停止了，请再运行一次安装程序，它会修复安装。
