# 恢复短语

恢复短语就是你的加密密钥，只不过写成了 24 个单词。它是读取你备份的唯一途径。

> 如果恢复短语和电脑都丢了，你的备份也就没了。没有人能把它们找回来：你的存储服务商不能，Permafrost 不能，frost 的作者也不能。

## 妥善保管

设置程序在生成密钥时会把恢复短语展示给你。把它抄在纸上，或者存进你信任的密码管理器，并放在你要备份的这台电脑之外的地方。

你的电脑上也有一份副本，保存在 frost 配置文件夹中的 `key` 文件里，这样计划备份才能在你不在场时运行。在 macOS 和 Linux 上，frost 创建这个文件时，只给你的用户读写权限。在 Windows 上，它继承用户配置文件的权限。共享文件夹或更改过的权限可能让其他人也能读取它。任何能读取这个文件或能以你的身份运行程序的人，都能读取你的备份，所以请使用全盘加密并设置锁屏。

要读取你的备份，一个人需要同时拥有恢复短语和你的存储访问权限。请同样妥善保管你的存储密钥。

## 显示恢复短语

```sh
frost key show
```

frost 会先提醒你，只有在你输入 `show` 之后才会显示恢复短语。请确认没有人在看你的屏幕，你也没有在共享屏幕。

## 核对你抄写的内容

```sh
frost key verify
```

输入你抄写下来的恢复短语。frost 会告诉你它是不是有效的恢复短语、是否与这台电脑上的密钥一致，以及能否打开你的备份。它永远不会把恢复短语打印出来。请时不时核对一下。

## 在另一台电脑上使用

当 `frost init` 连接到已有你备份的存储时，会要求输入恢复短语。要直接把它导入一台电脑：

```sh
frost key import
```

如果已经设置了存储，frost 会先检查这个恢复短语能否打开它。如果电脑上已经有另一个密钥，frost 会在替换之前询问你。用旧密钥创建的备份，恢复时需要旧的恢复短语。

完整步骤请参见[在新电脑上恢复](#new-computer)。

## 输入恢复短语

按顺序输入全部 24 个单词，单词之间用空格分隔。大小写无所谓。这些单词来自标准的 BIP39 英文词表，共 2,048 个单词，所以拼错时 frost 能告诉你：

| frost 的提示 | 含义 |
| --- | --- |
| that's 23 words, a recovery phrase has 24 | 少了一个或多了一个单词 |
| word 5, "hapy", isn't a recovery phrase word | 这个单词拼错了 |
| all the words are real, but they don't make a valid phrase | 有两个单词顺序颠倒，或者某个单词被换成了另一个真实存在的单词 |
| that's a valid phrase, but not the one for these backups | 这个恢复短语属于另一组备份 |

## 密钥指纹

指纹是一个简短的 ID，比如 `6f154dc10058`，它能标识你的密钥而不会泄露密钥。`frost status` 会显示它，在快照浏览器中按 `[v]` 也能看到。指纹相同的两台电脑，拥有的是同一个密钥。

## 更换密钥

frost 无法更换已有备份的密钥。如果别人可能看到过你的恢复短语，只要他们还能访问你的存储，就能读取这些备份，所以请更换你的存储密钥，并妥善保管。
