# 安全与隐私

在上传任何内容之前，frost 会在你的电脑上，用只有你持有的密钥加密你的备份。你的存储服务商、Permafrost 的运营方以及 frost 的作者都读不到它们。

## 哪些内容会被加密

frost 会加密备份中的所有内容：文件内容、文件名、文件夹结构以及每个快照的详细信息。frost 从不把密钥发送到服务器，也不保留用于代管恢复的副本。

| 组成部分 | 方式 |
| --- | --- |
| 密钥 | 256 个随机位，由 `frost init` 在你的电脑上生成 |
| 恢复短语 | 密钥本身，写成 24 个 BIP39 单词 |
| 加密 | XChaCha20-Poly1305，每个对象使用一个新的随机 nonce |
| 数据块名称 | 以你的密钥为密钥，对数据块内容计算的 HMAC-SHA256 |
| 压缩 | zstd，在加密之前进行，只在能让数据变小时才压缩 |

## 你的服务商能看到什么

你的存储服务商，无论是 S3 托管商还是 Permafrost，能看到：

- 你有多少个对象、每个对象多大、什么时候上传的。
- 哪些对象是数据块、快照头信息或文件列表索引。
- 你什么时候备份和恢复，以及使用的 IP 地址。
- 每次备份上传了多少新数据，这能大致反映有多少内容发生了变化。没有新内容的备份不会保存快照，所以新快照的出现意味着有东西变了。
- 一个小文件压缩后的大致大小，但看不到它是什么文件、叫什么名字。大文件会被拆分成大小不一的数据块，所以不会以一个与文件同样大小的对象出现。

服务商无法检查你是否拥有某个已知的文件。数据块的名称和拆分位置都取决于你的密钥。

## frost 能防范什么

- 你的服务商，或者拿到你存储桶副本的人，读取你的文件。
- 你和存储之间网络上的人。连接使用 TLS，除非你选择了 `http://` 的 S3 端点，或者对未指定协议的端点启用了 `storage.s3.insecure`。Permafrost 只允许你自己电脑上的服务器使用 `http://`。明文 HTTP 仅用于本地测试。无论是否使用 TLS，每个备份对象都会经过认证。
- 篡改。被修改、调换或截断的对象无法解密，frost 绝不会默默接受它们。
- 恢复时把文件写到你所选文件夹之外的地方。
- 被篡改的 frost 下载文件。每个发布版本都有签名，安装程序和 `frost update` 在安装任何东西之前都会检查签名。

## frost 无法防范什么

- **能接触你电脑的人。** 密钥文件保存在你的电脑上，这样计划备份才能运行。任何能读取它或能以你的身份运行程序的人，都能读取你的备份。请使用全盘加密并设置锁屏。
- **存储中的数据丢失。** 你的服务商可能删除或扣留你的对象。抽查可以发现这类问题，但 frost 无法阻止。对于丢不起的内容，请另外保留一份独立的副本。
- **被隐藏的快照。** 服务商可以藏起你最新的快照，只提供旧的。见过新快照的电脑会报告它们缺失，但新电脑无从察觉。不过，提供出来的每个快照依然是真实的。
- **时间和大小。** 如上所述，你什么时候备份、备份了多少，都是可见的。

## 你电脑上的文件

在 macOS 和 Linux 上，frost 创建私密文件时，只给你的用户访问权限。已有文件的权限以及计划程序创建的日志权限可能不同。在 Windows 上，文件继承用户配置文件的权限。请把配置和缓存放在其他用户无法读取的文件夹中。

| 文件 | 内容 |
| --- | --- |
| `key` | 你的恢复短语，明文保存 |
| `config.toml` | 你的设置和存储凭据 |
| `manifest-*.jsonl` | 数据块 ID、文件路径、大小和修改时间。它永远不会离开你的电脑 |
| `frost.log` | 计划备份的输出，包括无法读取的路径 |

[文件与文件夹](#files-and-folders)列出了它们的位置。

## 建议

- 离线保存你的恢复短语，写在纸上，或者存进你信任的密码管理器。
- 时不时运行一下 `frost key verify`，确认你抄写的恢复短语是对的。
- 给 frost 的存储凭据只开放它自己的存储桶。
- 时不时看一下 `frost status`，发现任何健康问题都要立即处理。

## 报告安全问题

请不要提交公开的 issue。请在 frost 的 GitHub 仓库的 [Security 标签页](https://github.com/whatithasisandalwayswillbe/frost/security)中，通过 **Report a vulnerability** 私下报告。请说明你发现了什么、如何复现，以及攻击者能借此获得什么。你会在一周内收到回复。
