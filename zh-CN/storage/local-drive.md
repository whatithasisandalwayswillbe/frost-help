# 本地磁盘

把备份存到磁盘上的一个文件夹里：外接 USB 磁盘、第二块内置磁盘，或者扩展坞中的磁盘。所有内容都会像存到其他存储时一样加密，所以磁盘丢了也不会泄露你的文件。

## 在设置程序中

运行 `frost init`，选择 **Local drive**，然后输入已连接磁盘上某个文件夹的完整路径。

| 系统 | 示例 |
| --- | --- |
| macOS | `/Volumes/Backup/frost` |
| Linux | `/mnt/backup/frost` 或 `/media/<you>/Backup/frost` |
| Windows | `E:\frost` |

如果路径的最后一级文件夹不存在，设置程序会创建它。它所在的上级文件夹，通常就是磁盘本身，必须存在。

## 磁盘未连接时

Frost 只在设置时创建文件夹。如果备份运行时磁盘没有连接，文件夹就不存在，备份会失败，并提示你连接磁盘。它绝不会把备份写到那个路径上的其他东西里。计划备份会先等待磁盘大约 5 分钟，以防磁盘还在挂载中。

在 Windows 上，重新插入磁盘时它可能会分到另一个盘符。请在“磁盘管理”中把旧盘符改回来，或者运行 `frost init` 并输入新路径。

## 在别处另存一份

放在电脑旁边的磁盘可能会和电脑一起丢失、被盗或损坏。对于无法替代的内容，请在别处另存一份，比如放在家以外的磁盘，或者位于另一个地方的[自托管](#self-hosted)服务器。复制仓库的方法见[迁移备份](#moving-backups)。

## 网络共享

对于 NAS，[自托管](#self-hosted)通常是更好的选择。挂载到电脑上的网络共享，只有在它的文件系统能安全创建文件时才能使用，设置程序会在连接时检查这一点。在 Windows 上，请使用共享的 `\\server\share` 路径，而不是映射的盘符，因为计划备份可能看不到映射的盘符。

## 注意事项

- Frost 不会跟随文件夹中的链接或联接点。在 Windows 上，它也会拒绝经由链接或联接点到达的文件夹。请使用文件夹的真实路径。
- 在 macOS 上，计划备份需要获得使用可移除磁盘和网络磁盘的权限。参见[macOS 权限](#macos-permissions)。
- `frost status` 会显示磁盘的使用情况，`frost backup` 会在快满时发出警告。
- 格式化为 NTFS、APFS、ext4、Btrfs 或 XFS 的磁盘可以使用。exFAT 和 FAT 磁盘在通过设置程序的检查时可以使用。
