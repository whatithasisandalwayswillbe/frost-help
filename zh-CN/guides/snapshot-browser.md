# 快照浏览器

`frost browse` 会打开一个全屏的快照浏览器。你可以按当时的样子浏览文件、比较快照，并恢复你选中的内容。

```sh
frost browse
```

`frost restore` 后面什么都不加，也会打开浏览器。浏览器打开时，计划备份照常可以运行。

## 移动

| 按键 | 作用 |
| --- | --- |
| `[↑]` `[↓]` 或 `[k]` `[j]` | 移动 |
| `[pgup]` `[pgdn]` | 一次移动一页 |
| `[g]` `[G]` | 跳到顶部或底部 |
| `[enter]` | 打开 |
| `[esc]` | 返回，或关闭错误提示 |
| `[h]` | 显示所有按键 |
| `[s]` | 显示你的设置 |
| `[v]` | 显示或隐藏密钥指纹 |
| `[q]` | 退出 |

设置界面是只读的。要修改设置，请使用 `frost config set` 或 `frost config edit`。

## 主界面

主界面显示上一次备份和最近一次健康检查的结果。按 `[enter]` 浏览快照，按 `[r]` 刷新。

## 快照

快照按从新到旧排列，并按日期分组。窗口足够宽时，列表旁边会有一个面板，显示当前高亮快照的详细信息：拍摄时间、在哪台电脑上、包含多少文件、总大小，以及新增了多少数据。

| 按键 | 作用 |
| --- | --- |
| `[enter]` | 打开这个快照中的文件 |
| `[d]` | 与上一个快照比较 |
| `[m]` | 标记这个快照。然后在另一个快照上按 `[d]`，比较这两个快照 |

比较结果会列出两个快照之间新增、删除和修改的内容。

## 文件

你看到的文件夹和文件，与那个快照中的样子完全一致。

| 按键 | 作用 |
| --- | --- |
| `[enter]` | 打开文件夹 |
| `[←]` | 返回上一级文件夹 |
| `[space]` | 选中或取消选中 |
| `[a]` | 选中或取消选中这个文件夹中的所有内容 |
| `[c]` | 清除选择 |
| `[r]` | 恢复选中的内容；如果什么都没选，就恢复当前高亮的项目 |

## 恢复

按 `[r]` 之后，选择文件恢复到哪里：

| 按键 | 选项 | 作用 |
| --- | --- | --- |
| `[1]` | New folder beside originals | 恢复到原文件旁边的新文件夹中，与 `frost restore --beside` 相同 |
| `[2]` | New folder elsewhere | 让你选择一个文件夹，然后恢复到其中的新文件夹 |
| `[3]` | Overwrite original files | 替换原文件，与 `frost restore --overwrite` 相同。按 `[y]` 确认 |

在写入任何内容之前，frost 会先显示每样东西会落在哪里。按 `[enter]` 恢复，按 `[c]` 更换文件夹，按 `[esc]` 取消。较长的确认信息和结果可以用 `[pgup]` 和 `[pgdn]` 滚动。

"New folder elsewhere" 会打开系统的文件夹选择器：macOS 上是访达，Windows 上是文件资源管理器，Linux 上是 zenity、qarma 或 matedialog。通过 SSH 连接时，或者 Linux 上没有选择器时，需要手动输入文件夹。选择器打开时按 `[t]`，也可以改为手动输入。

恢复完成后，frost 会在访达、文件资源管理器或你的 Linux 文件管理器中显示恢复的内容。如果只恢复了一个文件，会选中显示它；否则会打开包含所有内容的文件夹。通过 SSH 连接、没有图形界面或者恢复失败时，不会打开任何窗口。

[恢复文件](#restoring)详细介绍了每个选项，以及恢复中断时会发生什么。
