# 在新电脑上恢复

如果你的电脑丢失、损坏或者换了新的，你可以在另一台电脑上找回文件。

## 你需要准备什么

- 你的 24 个单词的恢复短语。
- 你的存储信息：Permafrost 访问密钥，或者 S3 服务商的存储桶名称和访问密钥。

如果旧电脑还在，`frost key show` 可以显示恢复短语。

## 步骤

1. 在新电脑上[安装 frost](#installing)。
2. 运行 `frost init`，选择同一个存储，填写与之前相同的信息。
3. 设置程序会找到你的备份，并要求输入它们的恢复短语。输入全部 24 个单词。
4. 选择这台电脑上要备份的文件夹、跳过列表和备份计划，然后确认并保存。
5. 在这台电脑第一次备份之前，恢复你的文件：

```sh
frost restore latest --to ~
```

这会把最新的快照恢复到主文件夹中一个新的 `frost-restore-<id>` 文件夹里，并按原来的文件夹结构排布。如果两台电脑是同一类系统，你可以加上旧电脑上的路径，只恢复其中一部分，比如 `/Users/you/Documents`。

如果快照来自另一类系统，比如在 Windows 上恢复 Mac 的快照，请使用快照浏览器挑选要恢复的内容。运行 `frost browse`，选中需要的内容并按 `[r]`，然后选择 "New folder elsewhere"。

请使用 `--to`，而不是 `--beside` 或 `--overwrite`。`--beside` 要求原来的文件夹在这台电脑上存在，`--overwrite` 要求快照来自同一类系统，即 macOS 和 Linux，或者 Windows。

> 请在这台电脑第一次备份之前恢复。备份之后，`latest` 就指向这台电脑自己最新的快照了。如果已经备份过，请运行 `frost status` 找到旧快照的 ID，改为恢复那个快照。

## 两台电脑共用一个存储

两台电脑可以用同一个恢复短语备份到同一个存储。它们的快照在同一个列表中，两台电脑都有的数据只存储一份。

这时，`latest` 指的是两台电脑中最新的那个快照。在快照浏览器中，详细信息面板会显示每个快照来自哪台电脑。要恢复某一台电脑的文件，请按 ID 选择它的快照。

## 恢复短语丢失时

如果旧电脑还能用，在上面运行 `frost key show`。如果恢复短语和电脑都没了，任何人都无法解密你的备份。参见[恢复短语](#recovery-phrase)。
